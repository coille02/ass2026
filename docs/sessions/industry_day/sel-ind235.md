# [퀀팃] 퀀트 개발 혁신: Bedrock 기반 자율형 AI 알파 팩토리

[Industry Day 전체 요약으로 돌아가기](../../industry_day_summary.md)

## 세션 정보

- 시간: 2026-05-20 15:30-15:50 KST
- 트랙: Track 3
- 발표자: 한덕희(CEO, 퀀팃)

## 발표 주제

이 세션은 퀀팃이 투자 아이디어를 실제 백테스트 가능한 퀀트 전략으로 바꾸는 과정을 Amazon Bedrock 기반 멀티 에이전트 시스템으로 자동화한 사례를 소개한 발표다. 퀀트 전략 개발에서 아이디어 정리, 데이터 조달, 코딩, 패턴 분석, 백테스트, 리스크 검토가 수작업으로 오래 걸리는 병목을 AI 에이전트 워크플로로 줄이는 것이 핵심이다.

발표는 Arkraft라는 자율형 AI 알파 팩토리의 구조, Bedrock 기반 멀티 에이전트 설계, Claude Code SDK 활용, OpenSearch와 EKS 기반 운영, Ralph Loop 다단계 추론, 향후 무인 알파 생산 체계로의 확장을 다뤘다.

## 주요 내용

- 퀀트 전략 개발은 투자 아이디어를 실제 코드와 백테스트 결과로 바꾸기까지 여러 전문 작업이 이어지는 긴 프로세스다.
- 퀀팃은 이 과정을 Arkraft라는 Bedrock 기반 멀티 에이전트 워크플로로 자동화하고 있다고 소개했다.
- 리서치 플랜 생성, 데이터 분석, Python 코드 작성, 백테스트, 통계·경제적 타당성 평가가 에이전트 단계로 연결된다.
- 발표에서는 한 시간 안에 알파 후보를 생산하는 구조를 목표로 제시했다.
- Claude Code SDK는 전략 코드 작성과 수정에 활용되고, Bedrock은 에이전트 추론과 오케스트레이션 기반으로 사용된다.
- OpenSearch와 RAG는 기존 아이디어와 리서치 맥락을 축적하고 재사용하는 기반으로 언급됐다.
- 향후에는 데이터 조달 에이전트, 운영 모니터링 에이전트, 전략 라이프사이클 관리로 확장하는 방향이 소개됐다.

## 세부 내용

### 퀀트 전략 개발의 병목

발표에서는 퀀트 투자의 알파 발굴 과정이 여전히 많은 수작업에 의존한다고 설명했다. 투자 아이디어를 정리하고, 필요한 데이터를 찾고, 전략을 코드로 구현하고, 백테스트를 수행한 뒤, 통계적 유의성과 경제적 타당성을 검토해야 한다.

이 과정은 연구자와 개발자의 반복 협업이 필요하고, 아이디어가 많아질수록 검증 병목이 커진다. 퀀팃은 이 반복 과정을 에이전트 워크플로로 전환해 아이디어 탐색 속도를 높이려 했다.

### Arkraft와 멀티 에이전트 구조

Arkraft는 투자 아이디어를 입력으로 받아 전략 후보를 생성하고 검증하는 자율형 AI 알파 팩토리로 소개됐다. 하나의 거대한 에이전트가 모든 일을 처리하기보다, 리서치 계획, 데이터 분석, 코드 작성, 백테스트, 리스크 분석 등 역할별 에이전트가 협업하는 구조다.

발표에서는 Bedrock 기반 에이전트와 Claude Code SDK가 전략 코드 생성에 활용된다고 설명했다. 에이전트는 데이터를 살펴보고 가설을 세운 뒤, Python 코드로 전략을 구현하고 백테스트 결과를 해석한다.

### Ralph Loop와 평가

퀀트 전략은 코드가 실행된다고 끝나는 것이 아니다. 통계적으로 우연한 결과인지, 경제적으로 설명 가능한지, 리스크가 과도하지 않은지 검토해야 한다. 발표에서는 Ralph Loop라는 다단계 추론 흐름을 통해 분석 품질을 높이는 접근이 소개됐다.

에이전트는 백테스트 결과를 바탕으로 전략의 장단점을 평가하고, 필요하면 가설과 코드를 수정한다. 이 반복 구조는 사람이 수행하던 리서치 리뷰 과정을 일부 자동화하는 방향으로 이해할 수 있다.

### 지식 축적과 확장

발표에서는 OpenSearch와 RAG 기반으로 기존 투자 아이디어, 리서치 기록, 전략 결과를 축적하는 구조도 언급됐다. 새로운 아이디어가 들어왔을 때 과거의 유사 사례와 결과를 참조하면 중복 실험을 줄이고 더 나은 가설을 만들 수 있다.

향후에는 데이터 조달 에이전트, 운영 모니터링 에이전트, 전략 배포 이후 성과 추적까지 확장해 알파 개발 라이프사이클 전반을 자동화하는 방향이 제시됐다.

## 정리

이 세션의 핵심은 퀀트 전략 개발을 수작업 중심 연구 프로세스에서 에이전트 기반 반복 실험 시스템으로 전환하려는 시도다. 퀀팃은 Bedrock, Claude Code SDK, OpenSearch, EKS를 조합해 아이디어 생성부터 코드 작성, 백테스트, 평가까지 연결했다.

발표는 금융 AI가 단순 리포트 생성에 머무르지 않고, 실제 전략 개발과 검증 과정을 자동화하는 방향으로 확장되고 있음을 보여줬다.
