### 배경과 문제 인식

GS SHOP은 Bedrock 위에서 TwelveLabs 비디오 이해 모델을 활용해 영상 기반 초개인화 추천 시스템을 구축했습니다. 메타데이터 기반 추천을 넘어, 영상 속 장면·분위기·스타일을 이해하여 고객 취향에 꼭 맞는 상품을 제안합니다. 실제 커머스 환경에 생성형 AI를 적용하며 마주한 기술적 도전과 해결 과정, 추천 정확도 향상 성과를 공유합니다.

발표는 이 배경에서 출발해 실제 서비스나 운영 환경에서 어떤 제약이 있었고, 이를 해결하기 위해 어떤 기술 선택과 구현 방식을 택했는지를 설명했다. 단순한 기능 소개보다 현장에서 마주한 병목, 데이터 흐름, 운영 책임을 어떻게 정리했는지가 핵심 맥락이다.
