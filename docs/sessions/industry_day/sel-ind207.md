# [현대카드] 현대카드 데이터 사이언스 플랫폼 진화 여정: Hybrid to Coding 에이전트

## 발표 주제

이 세션은 현대카드가 금융권 규제 환경에서 데이터 사이언스 플랫폼을 하이브리드 구조로 진화시키고, SageMaker 환경에 특화된 코딩 에이전트를 구축한 과정을 공유한 발표다. 민감 데이터와 비식별 데이터, 자체 GPU와 클라우드 자원, 내부 LLM과 Bedrock 접근을 데이터 성격과 보안 요구에 맞게 조합한 사례가 중심이다.

발표는 금융권 생성형 AI 인프라 선택지, 현대카드 HDSP의 구조, 온프레미스와 AWS를 함께 쓰는 개발 경험, 사내 코딩 에이전트 코드버프의 설계와 데모 순서로 전개됐다.

## 주요 내용

- 금융권 AI 인프라는 자체 GPU 기반 모델 서빙과 Bedrock 기반 관리형 모델 접근을 데이터 성격에 따라 병행할 수 있다고 설명했다.
- HDSP는 온프레미스 GPU를 학습에 활용하고, AWS SageMaker Pipeline과 endpoint를 serving과 workflow에 활용하는 투트랙 구조로 소개됐다.
- 동일 Docker 이미지와 HDSP 엔진을 통해 같은 코드가 SageMaker와 온프레미스 Jupyter/Kubernetes 양쪽에서 동작하도록 했다.
- 온프레미스 유휴 GPU를 적극 활용해 학습 비용과 GPU 부족 문제를 줄이고, GPU/CPU 사용 비중을 개선한 경험이 공유됐다.
- 코드버프는 사내 private LLM, RAG, 미들웨어와 툴, 멀티 에이전트를 결합해 SageMaker Notebook 안에서 코드 생성과 리뷰, 보안 검사를 지원한다.
- planner와 6개 도메인별 sub-agent가 Python, Athena query, Airflow DAG, Spark script, SageMaker tuning 등 역할을 나눠 담당한다.
- 노트북 요약, 보안 취약 코드 검출, 코드 리뷰, notebook 자동 생성, 인프라 스펙에 맞는 pandas/Polars/Dask/cuDF 권고가 데모로 제시됐다.

## 세부 내용

### 금융권 하이브리드 AI 전략

AWS 발표 파트에서는 금융권 생성형 AI 도입에서 데이터 민감도와 규제 환경을 고려해야 한다고 설명했다. 민감 데이터는 내부망과 자체 GPU 기반 오픈소스 모델로 처리하고, 비식별 데이터나 고성능 모델이 필요한 경우에는 Bedrock과 PrivateLink 기반 접근을 병행할 수 있다는 관점이다.

현대카드는 이러한 전략을 HDSP로 구체화했다. 온프레미스는 학습과 내부 자원 활용을 맡고, AWS는 SageMaker 기반 파이프라인과 엔드포인트, 워크플로를 담당한다. 두 환경을 분리된 섬으로 두지 않고 하나의 개발 경험으로 연결한 점이 발표의 핵심이었다.

### HDSP의 개발 경험

HDSP는 동일한 Docker 이미지와 엔진을 통해 개발자가 어디서 실행하든 같은 코드 경험을 갖도록 설계됐다. SageMaker와 온프레미스 Jupyter/Kubernetes 환경에서 같은 코드가 동작하면, 개발자는 인프라 차이보다 모델과 데이터 작업에 집중할 수 있다.

발표에서는 온프레미스 유휴 GPU를 활용해 비용과 자원 부족 문제를 줄인 점도 강조됐다. 학습 워크로드를 내부 GPU로 처리하고 필요한 serving과 workflow를 AWS로 연결하면서 금융권의 보안 요구와 클라우드의 확장성을 함께 활용하는 구조다.

### 코드버프 에이전트

코드버프는 일반 코딩 도구를 그대로 도입한 것이 아니라 SageMaker Notebook과 금융권 보안 맥락에 맞춘 코딩 에이전트다. 내부 RAG, private LLM, 미들웨어, 도메인별 sub-agent를 결합해 데이터 사이언티스트의 반복 작업을 줄이고 코드 품질을 높이는 데 초점을 맞췄다.

데모에서는 노트북 내용을 요약하고, 보안상 위험한 코드를 찾아내며, 인프라 사양에 맞는 라이브러리 선택을 권고하는 모습이 제시됐다. 이는 코딩 에이전트가 단순 자동완성을 넘어 조직의 개발 표준과 인프라 맥락을 이해하는 방향으로 진화하고 있음을 보여준다.

## 정리

이 세션의 핵심은 금융권 AI 도입이 외부 도구 사용 여부의 문제가 아니라, 규제와 내부 데이터 조건에 맞춘 개발 플랫폼 재설계라는 점이다. 현대카드는 온프레미스와 AWS를 연결한 HDSP를 통해 비용, 보안, 개발 경험을 함께 다뤘다.

코드버프 사례는 코딩 에이전트를 조직 맥락에 맞게 플랫폼화한 예다. SageMaker Notebook, 내부 LLM, RAG, 보안 검사, 인프라 최적화가 결합되면서 금융권 데이터 사이언스 업무에 맞는 생산성 도구로 자리 잡는 방향이 제시됐다.
