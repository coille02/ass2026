## 발표 주제

이 세션은 피지컬 AI 학습에서 실 데이터와 합성 데이터를 어떻게 결합해 Sim-to-Real 간극을 줄일 수 있는지 다룬 발표다. 스트라드비젼은 자율주행 비전 AI 관점에서, 바이프로스트는 자율선박과 시뮬레이션 기반 합성 데이터 플랫폼 관점에서 데이터 전략을 설명했다.

발표의 핵심은 합성 데이터가 실 데이터를 대체하는 것이 아니라, 실제 환경에서 충분히 수집하기 어려운 엣지 케이스를 보강한다는 점이다. 두 사례 모두 AWS 기반 인프라 위에서 대규모 데이터 처리와 시뮬레이션, 학습 실험을 연결하는 방향으로 수렴했다.

## 주요 내용

- 피지컬 AI는 실제 세계에서 작동해야 하므로 비 오는 밤, 드문 장애물, 예외 상황처럼 수집이 어려운 데이터가 성능 병목이 된다.
- 스트라드비젼은 실주행 데이터, 생성 모델 기반 합성 데이터, 시뮬레이션 데이터를 함께 활용하는 데이터 플로우를 소개했다.
- 실도로 데이터에서 디지털 트윈을 만들고, 차량 움직임이나 날씨, 시간대, 환경 조건을 바꿔 새로운 학습 데이터를 생성하는 흐름이 설명됐다.
- 바이프로스트는 3D와 시뮬레이션 전문 인력이 없어도 AI 엔지니어가 Python과 UI로 현실적인 시나리오를 만들 수 있는 플랫폼 접근을 제시했다.
- 자율선박뿐 아니라 제조, 방산, 우주 등 물리 세계를 다루는 다양한 산업에서 합성 데이터가 학습 가속화에 쓰일 수 있다고 설명했다.
- 후반부에는 에이전트가 AWS 인프라에서 대규모 실험을 실행하고 다음 날 지표, 결과, 개선 권고를 리포트하는 운영 방식도 제시됐다.

## 세부 내용

### 피지컬 AI의 데이터 병목

발표자는 피지컬 AI의 핵심이 모델 구조만이 아니라 학습 데이터의 폭과 품질에 있다고 설명했다. 실제 도로와 해상 환경에서는 드문 사고 상황, 비정상 날씨, 야간 조건, 예측하기 어려운 객체를 충분히 모으기 어렵다.

이 때문에 실 데이터만으로 모든 엣지 케이스를 커버하기는 어렵다. 세션은 실 데이터가 현실성을 제공하고, 합성 데이터가 부족한 조건과 위험한 상황을 보강하며, 시뮬레이션이 반복 실험을 가능하게 하는 구조를 강조했다.

### 스트라드비젼의 실 데이터와 합성 데이터 결합

스트라드비젼은 자율주행 비전 AI 학습을 위해 수집된 실주행 데이터를 기반으로 디지털 트윈을 만들고, 다양한 조건을 바꾼 합성 데이터를 생성하는 흐름을 설명했다. 실세계에서 얻은 장면을 바탕으로 차량 움직임, 환경 조건, 날씨, 조명 등을 변경하면 모델이 더 넓은 상황을 학습할 수 있다.

이 접근은 실 데이터의 신뢰성과 합성 데이터의 확장성을 함께 활용한다. 중요한 것은 합성 데이터가 실제 배포 환경과 동떨어진 장면을 만드는 것이 아니라, 현실 데이터가 닿지 못하는 빈틈을 채우도록 설계하는 것이다.

### 바이프로스트의 시뮬레이션 플랫폼

바이프로스트는 AI 엔지니어가 복잡한 3D 제작 도구를 직접 다루지 않아도 시뮬레이션 환경과 시나리오를 만들 수 있는 플랫폼을 소개했다. Python 기반으로 세계, 날씨, 시간대, 객체, 행동 시나리오를 정의하고 합성 데이터를 생성하는 접근이다.

자율선박 사례에서는 실제 데이터를 수백 시간 규모의 시뮬레이션 데이터로 확장해 다양한 항해 조건과 예외 상황을 학습에 반영하는 방향이 설명됐다. 이는 자율주행뿐 아니라 물리 세계를 다루는 산업 전반에서 Sim-to-Real 격차를 줄이는 공통 전략으로 제시됐다.

## 정리

이 세션의 핵심은 피지컬 AI의 성능이 모델만이 아니라 데이터 전략에 크게 좌우된다는 점이다. 실 데이터는 현실성을 제공하고, 합성 데이터는 엣지 케이스와 반복 실험을 보강하며, 시뮬레이션은 안전하고 빠른 검증 환경을 만든다.

스트라드비젼과 바이프로스트 사례는 실 데이터와 합성 데이터를 경쟁 관계가 아니라 하나의 학습 파이프라인으로 결합해야 한다는 메시지를 전했다. Sim-to-Real 가속화는 더 많은 데이터가 아니라 더 전략적으로 구성된 데이터 흐름에서 출발한다.
