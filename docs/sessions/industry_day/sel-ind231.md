**핵심 요약**  
스트라드비젼과 바이프로스트는 피지컬 AI의 병목이 데이터, 특히 실세계에서 보기 어려운 엣지 케이스 데이터에 있음을 강조했다. 스트라드비젼은 자율주행 비전 AI 학습을 위해 실주행 데이터, 생성 모델 기반 합성 데이터, 시뮬레이션 데이터를 결합하는 데이터 플로우를 소개했다. 바이프로스트는 3D/시뮬레이션 전문 인력이 없어도 AI 엔지니어가 Python으로 현실적인 세계, 날씨, 시간대, 시나리오를 생성할 수 있는 플랫폼 접근을 설명했다. 두 사례 모두 AWS 인프라 위에서 실 데이터와 합성 데이터를 결합해 Sim-to-Real 간극을 줄이는 전략으로 수렴했다.

**주요 포인트**
- 비 오는 밤, 동물 출현 등 실도로에서 충분히 수집하기 어려운 한계 상황이 자율주행 모델 학습의 난제다.
- 스트라드비젼은 자체 데이터 파이프라인에 생성 모델 기반 합성 데이터와 시뮬레이션 기반 데이터를 추가했다.
- 실도로 데이터에서 디지털 트윈을 만들고, 차량 움직임이나 환경 조건을 바꾸어 새로운 합성 데이터를 생성하는 흐름이 소개됐다.
- 바이프로스트는 영화/게임 수준의 3D 제작 복잡성을 추상화해 AI 엔지니어가 코드와 클릭으로 시나리오를 만들게 했다.
- 발표 후반부는 에이전트가 AWS 인프라에서 대규모 실험을 실행하고, 다음 날 지표/결과/개선 권고를 리포트하는 미래 운영 방식을 제시했다.

**AWS/기술 키워드**  
AWS Cloud, Synthetic Data, Simulation, Digital Twin, Sim-to-Real, Physical AI, Autonomous Driving, Autonomous Ship, Python-based Scenario Generation, Agent-based Experiment Automation

**현장 메모로 남길 점**  
이 세션은 “합성 데이터가 실 데이터를 대체한다”가 아니라 “실 데이터가 닿지 못하는 상황을 합성 데이터가 보강한다”로 정리해야 정확하다. 스트라드비젼은 자율주행, 바이프로스트는 자율선박/물리 AI 플랫폼 관점이라 사례 대비가 선명하다.

**블로그용 한줄**  
피지컬 AI의 Sim-to-Real 격차를 줄이는 열쇠는 실 데이터와 합성 데이터를 경쟁시키는 것이 아니라 함께 흐르게 하는 데이터 전략이었다.
