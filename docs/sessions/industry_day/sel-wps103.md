## 발표 주제

이 패널은 국방 영역에서 AI와 클라우드가 전쟁 수행 방식, 무기체계 개발, 지휘통제 구조를 어떻게 바꾸고 있는지 논의한 세션이다. 발표자들은 국방 AI를 미래 구상이 아니라 이미 전장에서 활용되는 현재의 변화로 보고, 감시정찰 데이터 분석, 지휘 결심 지원, 피지컬 AI, 클라우드 기반 개발 환경, 데이터 분류와 보안 제도까지 함께 다뤘다.

발표는 전쟁의 중심이 무기 플랫폼에서 데이터와 AI로 이동했다는 문제의식에서 출발했다. 이어 Project Maven과 같은 해외 사례, 소프트웨어화되는 무기체계, 클라우드 기반 실험과 시뮬레이션의 필요성, 국내 국방 클라우드가 갖춰야 할 통제와 제도적 기반을 차례로 설명했다.

## 주요 내용

- 현대 전장 AI는 단일 제품이 아니라 감시정찰 데이터, 클라우드 인프라, AI 모델, 지휘통제 애플리케이션이 결합된 복합 생태계로 설명됐다.
- Project Maven, Palantir, AWS 클라우드 인프라, Anthropic 모델 사례를 통해 전장 데이터 분석과 지휘 결심 지원이 어떻게 연결되는지 소개했다.
- AI/ML 기반 무기체계는 납품 후 고정되는 하드웨어가 아니라 지속적으로 학습하고 업데이트되는 소프트웨어 중심 시스템으로 바뀌어야 한다고 강조했다.
- 전통적인 4-5년 개발 주기는 AI 기술 변화 속도를 따라가기 어렵기 때문에 클라우드 기반 실험, 시뮬레이션, 빠른 검증 환경이 필요하다고 설명했다.
- 국방 AI 도입의 핵심 쟁점은 클라우드를 쓸지 말지가 아니라 데이터 민감도에 따라 통제 수준을 세분화하고 책임과 보안 기준을 정교하게 설계하는 데 있다.
- 한국 국방 환경에서는 데이터 분류 체계, 보안 등급, 책임 소재, 공급망 보안 요건, 행정 규칙의 빠른 갱신이 중요한 과제로 제시됐다.

## 세부 내용

### 전쟁 구조의 변화

패널은 최근 전쟁에서 AI가 이미 감시정찰과 지휘 결심 분야에 활용되고 있다고 짚었다. 과거에는 전쟁을 무기체계 중심으로 이해했지만, 이제는 방대한 데이터를 빠르게 모으고 해석해 지휘관에게 의미 있는 판단 재료를 제공하는 역량이 경쟁력이 되고 있다는 설명이다.

Project Maven 사례는 이러한 변화의 상징으로 언급됐다. 전장 데이터를 클라우드에 모으고, AI 모델이 영상과 센서 정보를 분석하며, 지휘통제 시스템이 이를 작전 판단으로 연결하는 구조다. 발표에서는 현대 전장 AI가 특정 기업의 단일 기술이 아니라 클라우드, 데이터, 모델, 애플리케이션이 결합된 체계라는 점을 강조했다.

### 무기체계의 소프트웨어화

LIG D&A 발표자는 AI 기반 무기체계가 고정된 하드웨어 중심 개발 방식으로는 충분하지 않다고 설명했다. 무기체계도 자동차나 스마트폰처럼 운영 중 업데이트되고, 현장 데이터로 학습하며, 새로운 기능과 위협에 맞춰 계속 진화하는 구조가 되어야 한다는 관점이다.

이를 위해서는 대규모 학습 환경, 반복적인 시뮬레이션, 빠른 검증이 필요하다. 발표에서는 클라우드를 활용하면 자체 생성 데이터와 시뮬레이션 데이터를 기반으로 더 짧은 주기의 개발과 검증이 가능해지고, 닫힌 시스템이 아니라 확장 가능한 데이터 아키텍처를 만들 수 있다고 설명했다.

### 제도와 보안 과제

법·제도 관점에서는 데이터 분류와 책임 소재가 핵심 쟁점으로 다뤄졌다. AI가 특정 실행을 했을 때 책임을 누가 지는지, 어떤 데이터를 어떤 보안 수준으로 다룰 수 있는지, 클라우드 활용을 어떤 규칙으로 허용할 것인지가 아직 정교하게 정리되어야 한다는 지적이다.

미국 국방 환경에서는 데이터 민감도에 따라 클라우드 보안 등급을 세분화하고, 통제 수준을 달리 적용하는 접근이 언급됐다. 국내도 보안을 이유로 일괄 차단하는 방식보다 데이터 분류, 접근 통제, 인증, 감사, 공급망 보안을 체계화해 활용 가능한 영역을 넓히는 방향이 필요하다는 메시지가 제시됐다.

## 정리

이 세션의 핵심은 국방 AI가 단순한 기술 도입이 아니라 운영 플랫폼 전환이라는 점이다. AI로 운영되는 국방을 만들기 위해서는 데이터가 모이고, 클라우드에서 확장되며, 모델과 무기체계가 지속적으로 업데이트되고, 제도와 보안 체계가 이를 뒷받침해야 한다.

특히 발표자들은 작은 무기체계와 현장 단위부터 AI와 클라우드를 적용해 성과를 만들고, 그 경험을 기반으로 더 큰 전환을 추진하는 접근을 제안했다. 국방 AI의 관건은 기술 가능성만이 아니라 데이터, 인프라, 책임, 통제, 조직 인식이 함께 움직이는 구조를 만드는 데 있었다.
