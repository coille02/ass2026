## 발표 주제

이 세션은 Amazon이 고객 경험, 셀러 지원, 공급망, 물류 운영에 AI를 적용해 온 방식을 바탕으로 AWS의 AI 전략을 설명한 발표다. 발표자는 Amazon의 AI 전략을 거대한 비전 선언보다 고객 문제를 반복적으로 해결하는 실행 방식으로 소개했다.

발표는 생성형 AI에서 에이전틱 AI로 이동하는 흐름, Amazon 내부 적용 사례, 산업별 활용 가능성, Bedrock과 Claude를 포함한 AWS AI 서비스 전략으로 이어졌다. 핵심 메시지는 AI가 고객 경험을 개선하고 운영 효율을 높이는 전 가치사슬의 기술이 되어야 한다는 점이다.

## 주요 내용

- Amazon의 AI 전략은 낮은 가격, 넓은 선택지, 좋은 고객 경험이라는 기본 원칙을 AI로 확장하는 방향으로 설명됐다.
- 쇼핑 영역에서는 Rufus와 Help Me Decide 같은 AI 서비스가 고객의 탐색, 비교, 의사결정을 돕는 사례로 소개됐다.
- 셀러 영역에서는 사진과 간단한 설명을 바탕으로 상품 등록 콘텐츠를 생성해 판매자의 업무 부담을 줄이는 흐름이 언급됐다.
- 공급망과 물류에서는 Chronos 기반 시계열 예측, 로봇 자동화, 디지털 트윈, 강화학습을 활용해 수요 예측과 운영 최적화를 고도화하는 사례를 설명했다.
- AWS 관점에서는 Amazon Bedrock의 모델 선택권, Amazon Nova, Anthropic Claude 통합, 네트워크 격리와 거버넌스를 기업형 AI 운영의 기반으로 제시했다.
- 개발자와 비개발자가 에이전트를 만들 수 있는 환경, 데이터 소스와 MCP 서버 연결, Claude Code 활용 증가도 후반부 주요 주제로 다뤄졌다.

## 세부 내용

### 고객 경험 중심의 AI

발표자는 Amazon의 AI 전략을 고객 경험에서 출발한다고 설명했다. 고객은 더 낮은 가격, 더 많은 선택지, 더 나은 경험을 기대하며, Amazon은 이 요구를 쇼핑, 검색, 추천, 의사결정 지원 기능으로 풀어왔다.

Rufus와 Help Me Decide는 이러한 접근을 보여주는 사례로 언급됐다. 고객이 상품을 비교하거나 선택을 망설일 때 AI가 맥락을 이해하고 정보를 정리해 주는 방식이다. 여기서 AI는 별도 기능이라기보다 쇼핑 여정 안에 자연스럽게 들어가는 경험 계층으로 소개됐다.

### 운영과 공급망의 AI

Amazon의 AI 활용은 고객 접점에만 머물지 않았다. 셀러가 상품을 등록할 때 사진과 짧은 설명을 기반으로 상세 콘텐츠를 만드는 기능은 판매자의 반복 작업을 줄이는 사례로 설명됐다. 이는 AI가 고객뿐 아니라 플랫폼 참여자의 생산성을 높이는 도구가 될 수 있음을 보여준다.

공급망과 물류 영역에서는 Chronos 기반 수요 예측, 로봇 운영, NVIDIA Isaac을 활용한 디지털 트윈과 강화학습이 언급됐다. 발표는 AI가 예측, 자동화, 시뮬레이션을 연결해 물류 운영의 복잡도를 낮추고 더 빠른 의사결정을 가능하게 한다는 흐름으로 전개됐다.

### AWS AI 플랫폼 전략

후반부는 AWS가 이러한 경험을 고객에게 제공하는 방식에 집중했다. Amazon Bedrock은 다양한 모델을 선택하고 기업 환경에 맞게 연결하는 기반으로 소개됐고, Amazon Nova와 Anthropic Claude 같은 모델 선택지도 함께 언급됐다.

기업 환경에서 AI를 운영하려면 모델 성능뿐 아니라 데이터 연결, 네트워크 통제, 비용 관리, 보안과 감사가 필요하다. 발표에서는 개발자 또는 현업 사용자가 에이전트를 만들고, 여러 데이터 소스와 도구를 연결하며, 필요한 경우 Claude Code 같은 개발 도구를 활용하는 흐름이 점점 강해지고 있다고 설명했다.

## 정리

이 세션은 Amazon의 AI 전략을 고객 경험과 운영 효율을 동시에 개선하는 실행 전략으로 제시했다. AI는 쇼핑 추천이나 챗봇에 국한되지 않고 셀러 지원, 공급망 예측, 로봇 자동화, 개발자 생산성까지 이어지는 전사적 기술로 다뤄졌다.

AWS가 강조한 방향은 기업이 특정 모델 하나에 묶이지 않고, Bedrock을 중심으로 다양한 모델과 데이터, 도구를 연결해 안전하게 에이전틱 AI를 운영하는 것이다. 발표의 핵심은 AI를 빠르게 실험하는 것에서 나아가 고객과 운영 현장의 반복 문제를 제품화된 서비스로 바꾸는 실행력에 있었다.
