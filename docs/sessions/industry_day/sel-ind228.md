### 핵심 요약
SK텔레콤 세션은 기존 데이터 플랫폼이 사람을 위한 분석 환경이었다면 이제는 AI가 탐색하고 활용할 수 있는 AI-ready data platform으로 전환해야 한다는 문제의식에서 출발했다. 발표자는 많은 AI 프로젝트가 가시적 성과로 이어지지 못하는 이유로 데이터 탐색성, 사용성, 거버넌스의 단절을 지적했다. SK텔레콤은 중앙집중형 허브 앤 스포크 대신 각 플랫폼의 자율성을 유지하는 데이터 메시 방식을 선택하되, 기준과 거버넌스는 통합해야 한다고 설명했다. Amazon SageMaker Unified Studio와 Lake Formation을 활용해 분석 환경이 데이터에 접근하고, 복제 없이 데이터와 메타데이터, AI 자산을 연결하는 구조를 구현한 것이 핵심이다.

### 주요 포인트
- AI 프로젝트의 성과를 높이려면 모델보다 먼저 데이터 탐색성, 사용성, 거버넌스가 갖춰져야 함
- 기존 데이터 플랫폼은 사람이 데이터를 찾고 분석하는 데 초점이 있었지만 AI 시대에는 AI가 이해할 수 있는 메타데이터와 연결성이 필요
- SK텔레콤은 분산된 플랫폼을 무리하게 중앙 집중화하기보다 데이터 메시 방식으로 자율성과 확장성을 유지
- 거버넌스를 통합하지 않으면 데이터 기준이 통합되지 않으므로 공통 기준과 관리 체계는 반드시 필요하다고 강조
- SageMaker Unified Studio 기반 분석 환경에서 Lake Formation 권한을 통해 데이터에 접근하고 플랫폼 간 복제를 줄이는 방향을 선택

### AWS/기술 키워드
- Amazon SageMaker Unified Studio, AWS Lake Formation, Data Mesh, AI-ready Data Platform, 데이터 거버넌스, 메타데이터, 분석 환경, End-to-End AI 개발

### 현장 메모로 남길 점
- "AI에게 필요한 데이터 플랫폼"이라는 표현처럼 데이터 플랫폼의 사용자를 사람에서 AI 에이전트와 모델까지 확장해 봐야 한다는 관점이 선명했다.

### 블로그용 한줄
> SK텔레콤은 SageMaker Unified Studio를 중심으로 데이터, 메타데이터, AI 자산을 연결해 AI가 바로 활용할 수 있는 데이터 플랫폼으로 전환하고 있다.
