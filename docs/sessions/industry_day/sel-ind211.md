# [바비톡] 바비톡의 AX여정: 에이전틱 AI로 K-beauty를 바꾸다

[Industry Day 전체 요약으로 돌아가기](../../industry_day_summary.md)

## 세션 정보

- 시간: 2026-05-20 14:30-15:10 KST
- 트랙: Track 4
- 발표자: 박민주(솔루션즈 아키텍트, AWS), 최권열(CTO, 바비톡)

## 발표 주제

이 세션은 바비톡이 Amazon Bedrock 기반 에이전틱 AI를 활용해 K-beauty 서비스와 내부 개발 문화를 어떻게 바꾸고 있는지 공유한 발표다. 바비톡은 AI를 유행처럼 도입한 것이 아니라 리뷰 검수, 검색과 답변, 뷰티 상담, K-beauty 여행 가이드, 내부 에이전트 스튜디오로 이어지는 실제 비즈니스 문제 해결 수단으로 설명했다.

AWS 파트에서는 PoC가 프로덕션으로 이어지지 못하는 이유를 모델 선택과 비용, 에이전트 설계 속도, 운영 복잡도로 나누고, Bedrock, Strands SDK, AgentCore, AI-DLC를 해결책으로 제시했다.

## 주요 내용

- 바비톡은 1,000만 유저 서비스에서 리뷰 검수, 검색, 상담, 여행 가이드 같은 구체 문제를 중심으로 AI 활용을 확장했다.
- 리뷰 검수는 EventBridge, Lambda, Bedrock 기반 LLM, 운영팀 검수 매뉴얼을 연결해 시작했고 이후 관리자 콘솔까지 통합됐다.
- 운영팀 효율이 50% 증가하고 비정상 게시물 누락률을 0으로 낮춘 사례가 소개됐다.
- 초기 Claude 기반 모델에서 Amazon Nova 계열 모델을 함께 활용하며 비용과 성능을 최적화하고 모델 교체 유지보수 비용을 줄였다고 설명했다.
- AI 검색과 답변은 단일 LLM 에이전트에서 NLU, Dialogue Manager, NLG 역할을 분리한 멀티 에이전트 구조로 진화했다.
- K-beauty 여행 가이드는 Kiro, AgentCore, Strands, AI-DLC를 활용해 1명의 개발자가 1주일 만에 출시한 사례로 소개됐다.
- hallucination 대응을 위해 도구 우선순위, 참조 가능한 정보 범위, 검증 리포트, CI/CD 내 품질 리포트를 설계했다.
- 향후 AI Agent Studio를 통해 비개발자도 업무용 에이전트를 만들고 공유하는 구조를 준비 중이라고 밝혔다.

## 세부 내용

### 작은 문제에서 시작한 AI 적용

바비톡은 처음부터 거대한 AI 플랫폼을 만드는 방식보다, 실제 서비스와 운영에서 반복되는 문제를 하나씩 해결하는 접근을 취했다. 리뷰 검수는 대표적인 출발점이었다. 운영팀의 검수 매뉴얼과 Bedrock 기반 LLM을 연결해 게시물의 정책 위반 여부를 판단하고, 이후 관리자 콘솔까지 통합했다.

이 방식은 AI가 서비스 운영의 품질과 속도를 함께 높일 수 있음을 보여줬다. 발표에서는 운영팀 효율 증가와 비정상 게시물 누락률 개선이 구체 성과로 소개됐다.

### 멀티 에이전트와 모델 최적화

AI 검색과 답변은 단일 에이전트로 시작했지만, 이후 NLU, Dialogue Manager, NLG 등 역할을 나눈 멀티 에이전트 구조로 발전했다. 사용자의 의도를 이해하고, 대화 상태를 관리하며, 답변을 생성하는 역할을 분리하면 품질과 유지보수성이 좋아진다는 설명이다.

모델 선택도 비용과 성능을 함께 고려했다. 모든 업무에 고성능 모델을 쓰기보다, use case별로 Claude Sonnet과 Amazon Nova Micro, Lite, Pro 계열을 나눠 쓰며 비용과 성능을 최적화했다. 이는 모델 교체 가능성과 운영 비용을 함께 보는 전략으로 제시됐다.

### AI-DLC와 에이전트 개발 문화

K-beauty 여행 가이드는 개발 방식 변화의 사례로 소개됐다. Kiro, AgentCore Runtime, Strands Agents, AI-DLC를 결합해 일정, 시술 상품, 팝업스토어처럼 최신성과 실재 여부가 중요한 정보를 다루는 서비스를 빠르게 만들었다.

발표는 AI가 개발 속도만 높이는 것이 아니라 품질 검증과 배포 흐름에도 들어가야 한다고 설명했다. 검증 리포트와 CI/CD 품질 리포트, 도구 우선순위 설정은 에이전트를 실제 서비스로 운영하기 위한 장치로 다뤄졌다.

## 정리

이 세션의 핵심은 바비톡이 에이전틱 AI를 실제 비즈니스 문제를 빠르게 해결하는 방식으로 적용했다는 점이다. 리뷰 검수, 검색, 상담, 여행 가이드처럼 작은 단위의 성공을 쌓으며 모델, 비용, 품질, 운영 구조를 함께 다듬고 있다.

바비톡 사례는 AI 에이전트가 거창한 플랫폼 선언보다 작고 명확한 문제에서 출발할 때 빠르게 제품화될 수 있음을 보여줬다. 동시에 운영 품질과 비용, hallucination 대응, 비개발자 확산까지 고려해야 지속 가능한 에이전트 전략이 된다는 메시지가 담겨 있었다.
