- 시간: 2026-05-20 12:50-13:30 KST
- 트랙: Track 5
- 발표자: 조성철(시니어 솔루션즈 아키텍트, AWS), 조현영(리더, 포스코)

## 발표 주제

이 세션은 포스코 광양제철소가 설비 예지정비 업무에 AWS Kiro와 SageMaker MLOps를 결합해 모델 개발과 운영을 자동화한 사례를 소개한 발표다. 제철소의 수많은 설비에서 발생하는 센서 데이터와 장애 이력을 분석해 고장 전조를 빠르게 찾고, 현장 엔지니어가 AI 모델 개발 과정에 더 쉽게 참여하도록 만드는 것이 핵심이다.

발표는 예지정비의 기존 병목, Kiro를 활용한 분석과 코드 생성, SageMaker 기반 MLOps 파이프라인, 드리프트 감지와 재학습, 현장 적용 성과를 순서대로 다뤘다.

## 주요 내용

- 제철소 예지정비는 수천 개 설비의 센서 데이터와 장애 이력을 다뤄야 하며, 모델 하나를 만들고 배포하는 데 긴 시간이 걸렸다.
- 발표에서는 기존 분석과 모델 개발에 약 2주, 배포까지 포함하면 1개월 이상이 필요했던 구조가 소개됐다.
- Kiro는 장애 보고서와 센서 데이터를 바탕으로 전조 신호, 분석 후보, 모델 코드 생성을 지원하는 AI 에이전트로 설명됐다.
- 포스코는 InnoPince 기반 프로세스에서 모델 개발 시간을 2주 수준에서 2시간 수준으로 줄인 사례를 공유했다.
- SageMaker MLOps는 전처리, 훈련, 평가, 배포, 모니터링, 재학습을 자동화하는 운영 기반으로 제시됐다.
- SageMaker Model Monitor가 드리프트를 감지하면 재학습 파이프라인과 모델 교체로 이어지는 구조를 설계했다.
- 현장 도메인 지식과 AI 자동화를 결합해 예지정비 모델을 더 빠르게 만들고 확장하는 것이 세션의 중심 메시지였다.

## 세부 내용

### 예지정비의 병목

제철소 설비는 연속 공정의 일부이기 때문에 장애가 발생하면 생산 차질이 커질 수 있다. 예지정비는 고장 이전의 전조 신호를 찾아 선제적으로 대응하는 방식이지만, 실제 현장에서는 설비별 데이터 구조와 운전 조건이 달라 모델 개발이 쉽지 않다.

발표에서는 현장 엔지니어의 지식이 모델 개발의 핵심 입력이라고 강조했다. 단순히 센서 데이터를 알고리즘에 넣는 것이 아니라, 장애 보고서, 정비 이력, 운전 조건, 설비 특성을 함께 이해해야 의미 있는 전조 신호를 찾을 수 있다.

### Kiro를 활용한 모델 개발

Kiro는 요구사항 정의, 데이터 분석, 알고리즘 후보 추천, 모델 코드 생성 과정을 지원하는 도구로 소개됐다. 장애 보고서와 센서 데이터를 분석해 어떤 신호를 봐야 하는지 제안하고, 이를 바탕으로 모델 개발에 필요한 코드를 생성한다.

발표에서는 고장 사례를 대상으로 테스트했을 때 전문가가 개발한 로직과 유사한 수준의 정확도를 보이는 아이디어를 제시했다고 설명했다. 중요한 점은 Kiro가 현장 엔지니어를 대체하는 것이 아니라, 현장 지식을 구조화하고 반복적인 분석과 코드 작성 시간을 줄이는 역할을 한다는 것이다.

### SageMaker MLOps 운영 구조

모델을 빠르게 만드는 것만으로는 충분하지 않다. 예지정비 모델은 배포 이후에도 설비 상태, 운전 조건, 대정비 이후의 기준 변화에 따라 성능이 달라질 수 있다. 발표에서는 SageMaker MLOps를 활용해 모델 운영 과정을 자동화하는 구조를 설명했다.

전처리, 훈련, 평가, 배포, 모니터링이 파이프라인으로 연결되고, Model Monitor가 데이터 드리프트나 성능 저하를 감지하면 재학습과 모델 교체가 이어진다. 이를 통해 모델 개발을 일회성 프로젝트가 아니라 지속적인 운영 체계로 전환한다.

### 현장 적용과 확장

포스코는 예지정비 모델 개발 시간을 크게 줄이고, 고장 전조를 더 빠르게 탐지하는 방향의 성과를 공유했다. 발표에서는 14건 이상의 예지 성공과 분석 시간 40배 단축 같은 수치도 언급됐다.

향후에는 모델 공장을 선정하고 AWS 클라우드와 연계해 제조 현장 AI 적용 범위를 넓히는 계획이 소개됐다. 핵심은 현장 엔지니어가 직접 모델 개발과 개선 과정에 참여할 수 있는 구조를 만드는 것이다.

## 정리

이 세션의 핵심은 제조 AI의 병목이 알고리즘 자체보다 데이터 해석, 도메인 지식 반영, 운영 자동화에 있다는 점이다. 포스코는 Kiro로 현장 지식을 모델 개발 과정에 연결하고, SageMaker MLOps로 배포와 재학습을 자동화해 예지정비를 확장 가능한 체계로 만들었다.

발표는 제철소 같은 대규모 제조 현장에서 AI가 실질적인 성과를 내려면 개발 속도와 운영 안정성을 함께 설계해야 한다는 메시지를 전달했다.
