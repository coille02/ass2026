# [현대지에프홀딩스] SMUS 기반 전사 MLOps 플랫폼으로 실현한 데이터 혁명

[Industry Day 세션 목록으로 돌아가기](../../industry_day_sessions.md)

## 세션 정보

- 시간: 2026-05-20 15:30-15:50 KST
- 트랙: Track 2
- 발표자: 곽영화(Senior Solutions Architect, AWS), 김철중(책임, 현대지에프홀딩스)

## 발표 주제

이 세션은 현대백화점그룹이 Amazon SageMaker Unified Studio를 기반으로 그룹사 전체를 위한 표준 MLOps 플랫폼을 구축한 사례를 소개했다. 발표의 초점은 모델 하나를 만드는 것이 아니라, 여러 계열사의 데이터를 AI-ready 자산으로 만들고, 거버넌스와 보안, 운영 자동화를 갖춘 전사 플랫폼으로 확산하는 과정에 있었다.

현대지에프홀딩스는 H.Point 회원 데이터와 계열사 데이터를 활용해 DW와 ML 파이프라인을 연결하고, 데이터 카탈로그와 승인 흐름, Lake Formation 기반 권한 관리를 결합한 구조를 설명했다. 웨딩 예정 지수 같은 라이프 스코어 모델 운영 사례도 함께 소개됐다.

## 주요 내용

- AI 프로젝트의 병목은 모델 자체보다 AI-ready 데이터와 운영 가능한 MLOps 환경의 부재라고 설명했다.
- 현대백화점그룹은 14개 계열사와 1,600만 H.Point 회원, 연간 대규모 거래 데이터를 전사 AI 자산으로 전환하기 위해 플랫폼을 구축했다.
- Redshift Data Sharing을 통해 데이터를 복제하지 않고 필요한 계열사 데이터에 접근하는 구조를 만들었다.
- 데이터 카탈로그와 구독·승인 절차를 통해 데이터 소유자가 목적과 기간을 검토하고 권한을 부여하는 거버넌스를 적용했다.
- MLOps 파이프라인은 ETL, 피처 생성, 학습과 평가, 챔피언 모델 선정, 배치 추론, S3와 DW 적재, CRM·마케팅 활용까지 자동화했다.
- 웨딩 예정 모델은 변수와 데이터 규모를 확대하고 성능 지표를 개선하며, 표준 플랫폼이 실제 비즈니스 모델 운영에 쓰이는 사례로 제시됐다.

## 세부 내용

### 전사 데이터 플랫폼의 필요성

발표 전반부에서는 엔터프라이즈 AI를 위해 분석과 AI 환경, 데이터 사일로 해소, 거버넌스, 운영 확장성이 함께 필요하다고 설명했다. 현대백화점그룹처럼 계열사가 많은 조직에서는 데이터가 흩어져 있고 권한과 활용 목적도 다양하기 때문에, 데이터 접근과 모델 운영을 표준화하는 일이 중요하다.

현대지에프홀딩스는 H.Point DW를 중심으로 계열사 데이터를 수집하고 전처리하는 기반을 마련했다. 이때 데이터 복제를 최소화하면서도 필요한 분석 환경에서 데이터를 쓸 수 있도록 Redshift Data Sharing과 카탈로그 기반 접근 방식을 활용했다.

### SMUS 기반 MLOps 구조

SageMaker Unified Studio는 데이터 분석, 모델 개발, 파이프라인 운영을 하나의 작업 환경으로 묶는 기반으로 소개됐다. 발표에서는 데이터 ETL, 피처 생성, 학습, 평가, 배치 추론, 결과 적재가 자동화된 파이프라인으로 연결되는 구조를 설명했다.

데이터 거버넌스도 플랫폼의 핵심 요소였다. 사용자는 카탈로그에서 필요한 데이터 상품을 찾고, 데이터 소유자는 목적과 사용 기간을 검토한다. 승인된 접근은 Lake Formation 기반 권한으로 반영되어 분석가가 안전하게 데이터를 사용할 수 있다.

### 모델 운영과 확산

웨딩 예정 지수와 같은 라이프 스코어 모델은 이 플랫폼이 단순 인프라가 아니라 실제 마케팅과 CRM에 연결되는 운영 체계임을 보여주는 사례였다. 모델은 정기적으로 데이터를 받아 학습·평가되고, 선정된 모델이 배치 추론을 수행해 결과를 DW와 마케팅 시스템에서 활용할 수 있게 한다.

발표에서는 MVP로 검증한 뒤 표준 플랫폼으로 선정하고, 계열사 데이터 사이언티스트를 육성하며 전사 확산을 준비한 과정도 중요하게 다뤘다. 이는 기술 도입보다 조직이 반복적으로 모델을 운영할 수 있는 구조를 만드는 데 초점이 있었다.

## 정리

이 세션의 핵심은 전사 AI의 출발점이 AI-ready 데이터와 표준 MLOps 운영 체계라는 점이다. 현대지에프홀딩스는 SMUS 기반 플랫폼으로 데이터 접근, 모델 개발, 평가, 배포, 거버넌스를 하나의 흐름으로 묶었다.

특히 계열사 확산을 고려한 표준화와 승인 기반 데이터 거버넌스가 강점으로 제시됐다. 모델을 만드는 것보다 지속적으로 운영하고 여러 조직이 재사용할 수 있는 플랫폼을 만드는 것이 엔터프라이즈 AI의 핵심이라는 메시지가 선명했다.
