## 발표 주제

이 세션은 미래에셋증권이 ETF, 펀드, 채권 등 금융 상품의 정형·비정형 데이터를 GraphRAG 기반 상품지식DB로 전환한 과정을 소개한 발표다. 투자설명서, 리포트, 상품 속성, 관계 정보를 지식 그래프로 구조화하고, LLM 기반 질의응답에서 금융 상품 간 관계와 조건을 더 정확하게 탐색하는 것이 핵심이다.

발표는 일반 RAG의 한계, 금융 상품 데이터의 특성, 온톨로지와 지식 그래프 설계, Graph Query 변환, 관리자 검증, Amazon Neptune과 Amazon Bedrock Knowledge Bases 기반 확장 방향을 다뤘다.

## 주요 내용

- 금융 상품 데이터는 정형 속성과 투자설명서·리포트 같은 비정형 문서가 함께 존재해 단순 검색만으로는 정확한 답을 만들기 어렵다.
- 일반 RAG는 문서 유사도 검색에는 강하지만, 상품 간 관계, 조건, 수치, 계층 구조를 정확히 추론하는 데 한계가 있다.
- 미래에셋증권은 상품 정보를 온톨로지로 정리하고 엔티티와 관계를 지식 그래프로 구성하는 접근을 선택했다.
- GraphRAG는 자연어 질의를 그래프 질의로 변환해 관계 기반 탐색과 LLM 응답 생성을 결합한다.
- 구축 과정에서는 문서 파싱, 엔티티 추출, 관계 추출, 표준화, 임계값 조정, 관리자 검증 패널이 핵심 작업으로 소개됐다.
- Amazon Neptune 계열 그래프 데이터베이스와 Amazon Bedrock Knowledge Bases의 그래프 기능이 기술 기반으로 언급됐다.
- 향후에는 내부망 환경에서 Bedrock LLM을 활용하는 구조와 데이터 온톨로지 기반 확장을 계획으로 제시했다.

## 세부 내용

### AI-Ready Data의 의미

발표에서는 생성형 AI가 좋은 답을 하려면 데이터가 AI가 이해할 수 있는 구조로 준비되어야 한다고 설명했다. 금융 상품은 이름, 유형, 위험 등급, 수익 구조, 발행사, 기초 자산 같은 정형 데이터와 투자설명서, 리포트, 약관 같은 비정형 문서가 결합되어 있다.

단순히 문서를 벡터화하면 비슷한 문단은 찾을 수 있지만, 특정 상품이 어떤 자산과 연결되는지, 어떤 조건에서 수익이 달라지는지, 여러 상품의 관계가 어떻게 다른지까지 안정적으로 답하기 어렵다. 미래에셋증권은 이 문제를 데이터 구조화 관점에서 접근했다.

### GraphRAG와 상품지식DB

GraphRAG는 지식 그래프와 RAG를 결합하는 방식이다. 상품, 발행사, 자산, 섹터, 위험 요인 같은 개체를 노드로 만들고, 포함한다, 추종한다, 발행했다, 영향을 받는다 같은 관계를 엣지로 표현한다. 자연어 질의는 그래프 질의로 변환되어 관계를 탐색하고, 그 결과를 바탕으로 LLM이 답변을 생성한다.

발표에서는 이 방식이 금융 상품 질의에 적합한 이유를 설명했다. 금융 질의는 단순 문서 검색보다 관계와 조건이 중요하고, 답변 근거를 추적할 수 있어야 한다. 그래프 구조는 관계 기반 탐색과 근거 확인에 강점을 가진다.

### 구축 과정

구축 과정에서는 비정형 문서를 파싱하고, 문서 안의 상품명, 기관, 수치, 조건, 위험 요인을 추출하는 작업이 필요했다. 추출된 엔티티와 관계는 온톨로지에 맞춰 표준화되고, 중복이나 애매한 관계는 임계값과 검증 절차로 조정된다.

발표에서는 관리자 검증 패널의 중요성도 다뤘다. 금융 상품 정보는 정확성이 중요하기 때문에 자동 추출 결과를 그대로 쓰기보다 사람이 검토하고 승인할 수 있는 구조가 필요하다. 이 과정을 통해 상품지식DB의 신뢰도를 높인다.

### 기술 기반과 확장

기술적으로는 그래프 데이터베이스와 LLM 기반 질의 변환이 핵심이다. 발표에서는 Amazon Neptune 계열 그래프 데이터베이스와 Amazon Bedrock Knowledge Bases의 그래프 기능이 언급됐다. 내부망 환경에서 Bedrock LLM을 사용하는 구조도 향후 과제로 제시됐다.

장기적으로는 ETF, 펀드, 채권을 넘어 더 넓은 상품군과 리서치 데이터로 온톨로지를 확장할 수 있다. 중요한 것은 데이터를 문서 묶음으로 두는 것이 아니라, AI가 관계와 맥락을 추론할 수 있는 지식 구조로 바꾸는 것이다.

## 정리

이 세션의 핵심은 금융 AI의 품질이 모델보다 데이터 구조에 크게 좌우된다는 점이다. 미래에셋증권은 상품 정보를 지식 그래프로 전환하고 GraphRAG를 적용해 관계 탐색, 근거 확인, 자연어 질의응답을 결합했다.

발표는 금융 상품처럼 정확성과 설명 가능성이 중요한 영역에서 AI-Ready Data를 만드는 방법을 보여줬다. 단순 문서 검색을 넘어 온톨로지와 그래프 기반 지식DB를 설계하는 접근이 인상적이었다.
