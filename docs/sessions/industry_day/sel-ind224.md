# [Config] 피지컬 AI 기업 Config의 AWS 기반 Robotics Foundation Model 개발 여정

## 세션 정보

- 시간: 2026-05-20 12:50-13:23 KST
- 트랙: Track 6
- 발표자: 손형목(최고 기술 책임자, Config)

## 발표 주제

이 세션은 피지컬 AI 스타트업 Config가 양팔 로봇 작업에 특화된 VLA(Vision Language Action) 기반 Robotics Foundation Model을 개발하는 과정을 소개한 발표다. 핵심은 로봇 모델의 성능을 좌우하는 고품질 액션 데이터를 어떻게 대규모로 생산, 검수, 저장, 처리, 학습하는지에 있었다.

발표는 로봇 파운데이션 모델의 데이터 병목, 자체 데이터 생산 시설, 액션 데이터 품질 관리, AWS Direct Connect와 Amazon S3 기반 데이터 파이프라인, Amazon EKS와 GPU 인프라를 활용한 학습·추론 운영을 다뤘다.

## 주요 내용

- Config는 양팔 작업에 특화된 자체 VLA 모델을 개발하고 있으며, 다양한 엔터프라이즈 고객과 협업하고 있다고 소개했다.
- 로봇 파운데이션 모델은 텍스트나 이미지 모델보다 실제 세계의 액션 데이터 확보가 훨씬 큰 병목으로 제시됐다.
- 좋은 액션 데이터는 물체, 환경, 작업, 동작이 다양하게 분포되어야 하며, 데이터에 없는 상황까지 일반화할 수 있어야 한다.
- Config는 국내와 베트남에 데이터 생산 및 검수 시설을 구축해 월 20,000시간 이상의 액션 데이터를 수집한다고 설명했다.
- 발표에서는 누적 13만 시간 수준의 데이터와 월 2만-3만 시간 규모의 생산 능력도 언급됐다.
- AWS Direct Connect를 통해 데이터 생산 시설에서 Amazon S3와 DynamoDB로 데이터를 안정적으로 업로드한다.
- Amazon EKS, SageMaker HyperPod, H100/B200급 학습 인프라, L40S급 추론 인프라를 역할별로 활용해 비용과 성능을 조정한다.

## 세부 내용

### Robotics Foundation Model과 데이터

발표 초반에는 Robotics Foundation Model이 왜 어려운지 설명했다. 언어 모델은 텍스트, 비전 모델은 이미지와 영상 데이터를 대규모로 수집할 수 있지만, 로봇 모델에는 실제 행동 데이터가 필요하다. 로봇이 물체를 잡고, 옮기고, 조작하는 과정은 환경과 물체, 힘, 순서, 실패 상황까지 포함한다.

Config는 고품질 액션 데이터가 모델 성능의 핵심이라고 봤다. 단순히 많은 데이터를 모으는 것이 아니라, 다양한 물체와 환경, 작업 목표, 액션 패턴이 포함되어야 한다. 발표에서는 고객이 원하는 타깃 테스트가 정의되면 그에 맞는 데이터 분포와 평가 기준을 함께 설계해야 한다고 설명했다.

### 데이터 생산과 검수

Config는 로봇 액션 데이터를 확보하기 위해 자체 데이터 생산 인프라를 구축했다. 국내와 베트남 시설에서 사람이 원격 조작이나 작업 수행을 통해 데이터를 만들고, 품질 검수 절차를 통해 학습 가능한 데이터로 정리한다.

발표에서는 사람의 액션을 라벨링하고 품질을 자동 평가하는 과정도 언급됐다. 로봇 데이터는 작은 오류가 모델 학습 품질에 영향을 줄 수 있으므로, 데이터 생산량뿐 아니라 검수 체계와 표준화가 중요하다.

### AWS 기반 데이터 파이프라인

대규모 액션 데이터는 생성 지점에서 클라우드 학습 환경으로 안정적으로 이동해야 한다. Config는 AWS Direct Connect를 활용해 자체 시설과 AWS 환경을 연결하고, Amazon S3와 DynamoDB에 데이터를 저장한다. 발표에서는 Direct Connect가 데이터 업로드의 안정성과 비용 효율성을 높이는 데 도움이 됐다고 설명했다.

데이터 처리와 학습 파이프라인은 Amazon EKS 기반으로 구성됐다. 데이터 전처리, 검수 결과 반영, 학습 작업 준비, 메타데이터 관리가 연결되어 로봇 모델 학습에 필요한 데이터 흐름을 만든다.

### 학습과 추론 비용 최적화

로봇 파운데이션 모델 학습에는 고성능 GPU가 필요하지만, 모든 작업에 같은 GPU를 쓰는 것은 비용 효율적이지 않다. 발표에서는 학습에는 H100이나 B200급 노드를 활용하고, 추론에는 L40S 같은 상대적으로 비용 효율적인 인스턴스를 활용하는 방식이 소개됐다.

SageMaker HyperPod 같은 대규모 학습 인프라와 EKS 기반 운영 환경을 조합해 학습 안정성과 자원 활용률을 높이는 방향도 다뤄졌다. 피지컬 AI에서는 모델 학습뿐 아니라 데이터 이동, 저장, 전처리, 추론 비용까지 전체 파이프라인 관점에서 최적화해야 한다는 점이 강조됐다.

## 정리

이 세션의 핵심은 피지컬 AI에서는 모델보다 먼저 데이터 생산 체계가 필요하다는 점이다. Config는 자체 액션 데이터 생산 시설과 AWS 기반 데이터·학습 인프라를 결합해 로봇 파운데이션 모델 개발을 확장하고 있다.

발표는 로봇 AI가 실세계로 나아가려면 고품질 액션 데이터, 안정적인 데이터 파이프라인, 대규모 GPU 학습, 비용 효율적인 추론 구조가 함께 설계되어야 한다는 점을 보여줬다.
