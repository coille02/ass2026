# LG전자, 에이전틱 AI 기반 멀티에이전트 플랫폼 구축을 통한 업무혁신

## 세션 정보

- 시간: 2026-05-20 14:30-15:10 KST
- 트랙: Track 5
- 발표자: 문필재(팀장, LG전자 한국영업본부 AX플랫폼)

## 발표 주제

이 세션은 LG전자 한국영업본부가 정형·비정형·멀티모달 데이터를 다루는 멀티 에이전트 플랫폼 “Agent One”으로 업무 혁신을 추진한 사례를 소개했다. 고객 데이터 플랫폼과 대시보드 AI에서 출발해, 매장 교육, CRM, GEO 모니터링, 상담 기록 분석, 유튜브와 뉴스 분석, 실적 분석, CAD 도면 자동화까지 확장한 흐름이 중심이다.

발표는 AWS 인프라와 Amazon Bedrock, Transcribe, IVS, Redshift, Aurora, QuickSight 계열 기능을 조합해 여러 업무형 에이전트를 구성하고, 향후 현업 담당자가 직접 워크플로를 연결하는 방향을 제시했다.

## 주요 내용

- 기존 DX 조직은 CDP와 경영 지표 대시보드를 운영했고, 자연어로 고객 조건을 입력해 세그먼트를 추출하는 챗인사이트 형태를 만들었다.
- 2025년에는 내부·외부 데이터, API, 검색을 결합해 분석 리포트를 만드는 멀티 에이전트 Deep Analyst 형태로 확장했다.
- Agent One은 포털처럼 개별 에이전트를 호출하거나 planner가 적합한 에이전트를 선택하고 collector, coder, reporter 등이 역할을 나눠 결과를 만드는 구조로 설명됐다.
- Role Playing Agent는 판매 매니저 교육 영상을 IVS로 녹화해 S3에 저장하고, 영상·표정·제스처와 음성을 분리 분석해 Bedrock으로 평가 피드백을 생성한다.
- 구독 대시보드 챗봇은 QuickSight 필터 맥락을 이해해 현재 보고 있는 지역의 판매 트렌드나 지도 분석을 이어서 답변하는 방식으로 소개됐다.
- AutoGen CRM은 캠페인 기획, CDP 기반 타게팅, 세그먼트 생성, 카피라이팅, 이미지 생성, 발송, 성과 분석까지 여러 에이전트가 나눠 처리한다.
- GEO 모니터링은 AI 검색과 추천 시대에 LG전자 제품이 어떤 질문에서 어떻게 인용되고 추천되는지를 수집·분석하는 사례였다.
- CAD 도면 자동화는 공간 면적 산출, 제품 스펙 선정, 배치, 검토 자동화를 목표로 하며 전문점 설계 검토 자동화를 추진 중이라고 소개됐다.

## 세부 내용

### Agent One의 플랫폼 구조

LG전자 한국영업본부는 오프라인 매장, 온라인 판매, B2B 영업, 마케팅, 물류, 신제품 지원 등 다양한 업무를 수행한다. 이 때문에 AI 에이전트도 하나의 기능이 아니라 여러 업무 영역을 지원하는 플랫폼 형태로 설계됐다.

Agent One은 개별 에이전트를 포털에서 호출하거나, planner가 질문에 맞는 에이전트를 선택하고 여러 역할 에이전트가 협업해 결과를 만드는 구조로 설명됐다. 내부 데이터, 외부 검색, API, 분석 코드, 리포팅이 하나의 흐름 안에서 결합된다.

### 멀티모달 업무 사례

Role Playing Agent는 판매 매니저 교육을 위한 멀티모달 사례로 소개됐다. 교육 영상을 Amazon IVS로 녹화하고 S3에 저장한 뒤, 음성과 영상 요소를 분리해 분석한다. Bedrock은 평가 기준표를 바탕으로 피드백을 생성해 교육 품질을 높이는 데 쓰인다.

대시보드 챗봇은 사용자가 보고 있는 QuickSight 필터 맥락을 이해해 이어서 답변하는 방식이다. 단순 Q&A가 아니라 현재 보고 있는 지표와 지역, 상품 맥락을 유지한 채 분석을 이어가는 경험이 강조됐다.

### 업무 자동화 확장

AutoGen CRM은 캠페인 기획부터 성과 분석까지 여러 에이전트가 나눠 처리하는 사례다. CDP 기반 타게팅, 세그먼트 생성, 카피라이팅, 이미지 생성, 발송, 결과 분석이 하나의 에이전트 워크플로로 연결된다.

CAD 도면 자동화는 숙련 엔지니어의 암묵지가 필요한 업무를 AI가 보조하는 사례로 소개됐다. 공간 정보를 해석하고 제품 스펙을 선정하며 배치를 검토하는 과정은 멀티모달 추론과 도메인 지식이 함께 필요한 영역이다.

## 정리

이 세션의 핵심은 LG전자가 에이전트 하나가 아니라 영업본부 업무 전반에 작은 에이전트를 깔고, 이를 Agent One 플랫폼으로 묶어내려 한다는 점이다. 데이터 분석, 교육, CRM, 모니터링, CAD 도면 업무가 각각 다른 형태의 에이전트로 확장되고 있다.

발표의 방향은 현업 담당자가 직접 에이전트를 연결해 워크플로를 구성하는 플랫폼으로 나아가는 것이다. 멀티 에이전트 전략은 단일 챗봇보다 복잡하지만, 다양한 업무 맥락과 데이터 유형을 다루는 영업 조직에는 더 현실적인 접근으로 제시됐다.
