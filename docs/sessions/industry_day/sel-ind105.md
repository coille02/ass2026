# AWS 피지컬 AI로 실현하는 기업의 차세대 혁신 전략

## 세션 정보

- 시간: 2026-05-20 11:10-11:50 KST
- 트랙: Track 6
- 발표자: David Randle(Worldwide Head GTM - Physical AI, AWS)

## 발표 주제

이 세션은 AWS가 바라보는 피지컬 AI의 개념과 기업 혁신 전략을 소개한 발표다. 피지컬 AI는 디지털 모델이 실제 세계의 상태를 감지하고, 시뮬레이션하고, 검증한 뒤, 로봇·설비·차량 같은 물리 시스템의 행동으로 이어지게 만드는 흐름으로 설명됐다.

발표는 노동력 부족과 생산성 압박이라는 배경, AWS Physical AI Framework, IoT 센싱부터 엣지 자율성까지의 6단계 아키텍처, 디지털 트윈과 시뮬레이션, 클라우드와 엣지의 역할, 제조·자동차·로보틱스 적용 가능성을 다뤘다.

## 주요 내용

- 발표에서는 2030년 7조 달러 규모의 자율 경제 시대가 열릴 수 있다는 전망을 배경으로 피지컬 AI의 중요성을 설명했다.
- 피지컬 AI는 생성형 AI를 물리 세계의 센서, 설비, 로봇, 차량, 엣지 디바이스와 연결하는 접근이다.
- 핵심 흐름은 데이터 수집, 물리 상태 이해, 디지털 트윈, 대규모 시뮬레이션, 모델 검증, 엣지 실행, 운영 데이터 기반 재학습으로 이어진다.
- 클라우드는 대규모 데이터 처리와 시뮬레이션, 모델 학습의 기반으로 제시됐다.
- 엣지는 실제 현장에서 낮은 지연시간으로 판단하고 행동하는 실행 계층으로 설명됐다.
- 제조업에서는 생산성 향상, 품질 관리, 설비 자동화, 안전성 개선이 주요 활용 영역으로 소개됐다.
- 발표의 메시지는 피지컬 AI가 단일 기술이 아니라 클라우드, 엣지, 센서, 시뮬레이션, 운영 데이터가 만드는 플라이휠이라는 점이었다.

## 세부 내용

### 피지컬 AI의 배경

발표는 노동력 부족, 숙련 인력 감소, 생산성 압박이 물리 세계의 자동화 수요를 높이고 있다고 설명했다. 기존 자동화는 정해진 규칙과 반복 작업에 강했지만, 변화하는 환경과 예외 상황을 다루기에는 한계가 있었다.

피지컬 AI는 AI가 실제 세계의 맥락을 이해하고, 물리 시스템의 행동을 제어하거나 보조하는 방향으로 자동화를 확장한다. 제조, 물류, 자동차, 로보틱스처럼 현실 세계의 제약이 큰 영역에서 특히 중요한 변화로 제시됐다.

### AWS Physical AI Framework

발표에서는 AWS Physical AI Framework를 통해 피지컬 AI를 단계적으로 설명했다. 첫 단계는 IoT와 센서를 통해 물리 세계의 상태를 수집하는 것이다. 이후 데이터를 정리하고, 디지털 트윈으로 현실 환경을 표현하며, 클라우드에서 대규모 시뮬레이션과 학습을 수행한다.

검증된 모델은 엣지 환경으로 배포되어 실제 장비나 로봇의 판단과 행동을 지원한다. 운영 중 발생하는 데이터는 다시 클라우드로 돌아와 모델 개선과 시뮬레이션에 사용된다. 이 반복이 피지컬 AI 플라이휠을 만든다.

### 클라우드와 엣지의 역할

피지컬 AI에서는 클라우드와 엣지가 서로 다른 역할을 맡는다. 클라우드는 대규모 데이터 저장, 학습, 시뮬레이션, 여러 현장의 데이터 통합에 적합하다. 반면 엣지는 공장이나 현장 장비 가까이에서 낮은 지연시간으로 실행되어야 한다.

발표에서는 모든 것을 클라우드로 보내거나 모든 것을 현장에 두는 방식보다, 학습과 검증은 클라우드에서, 실시간 제어와 실행은 엣지에서 맡는 구조가 중요하다고 설명했다.

### 산업 적용 방향

제조업에서는 설비 상태 예측, 생산 라인 최적화, 품질 검사, 로봇 작업 자동화가 주요 적용 영역으로 제시됐다. 자동차와 자율주행 영역에서는 시뮬레이션 기반 검증과 실제 주행 데이터의 학습 루프가 중요하다.

발표는 피지컬 AI가 새로운 비즈니스 가치를 만들려면 기술 도입 자체보다 데이터 루프와 운영 모델을 설계해야 한다고 설명했다. 실제 현장에서 얻은 데이터를 다시 학습과 시뮬레이션에 반영하는 구조가 경쟁력을 만든다.

## 정리

이 세션의 핵심은 피지컬 AI가 디지털 AI를 실제 세계의 행동으로 확장하는 흐름이라는 점이다. AWS는 센서, 디지털 트윈, 시뮬레이션, 클라우드 학습, 엣지 실행, 운영 데이터 재학습을 하나의 아키텍처로 묶어 설명했다.

발표는 제조와 로보틱스 같은 산업에서 AI 혁신이 모델만으로 완성되지 않으며, 물리 세계의 데이터와 실행 구조를 함께 설계해야 한다는 메시지를 전달했다.
