## 발표 주제

속도의 시대, Agent-Driven 개발 환경(Claude Code, Kiro IDE, GitHub Copilot)으로 생산성은 기하급수적으로 향상되고 있습니다. 하지만 빠른 개발 속도만큼 보안 검토는 어려워지고 있습니다. 빠르게 변화하는 보안 위협 패턴, 보안 전문 지식 도메인을 완벽히 갖춘 AWS Security Agent로 대응하세요!

Claude Code, Kiro IDE, GitHub Copilot 같은 Agent-Driven 개발 환경에서는 코드 작성 속도가 보안 검토 속도를 압도하므로, 설계검토, 코드리뷰, 침투테스트를 자동화하는 AWS Security Agent 접근이 필요하다고 설명했다. 보안 요구사항을 조직별로 정의하고, PR 리뷰와 전체 코드 리뷰에서 취약점 탐지와 remediation 제안을 수행하는 흐름을 시연했다.

## 주요 내용

- AI 개발은 취약한 코드가 빠르게 생산·배포될 위험을 키운다.
- 보안은 배포 전 마지막 관문이 아니라 설계와 코드 작성 시점으로 당겨져야 한다.
- Security Agent는 설계검토, 코드리뷰, 침투테스트를 각각 수행하고, 취약점 체인과 권한 상승 가능성까지 검증한다.
- 단순히 “취약점 있음”을 알려주는 수준을 넘어 수정안과 리포트를 생성하는 것이 개발자 경험 측면에서 중요하다.

## 세부 내용

### 문제의식과 배경

AI 개발은 취약한 코드가 빠르게 생산·배포될 위험을 키운다. 보안은 배포 전 마지막 관문이 아니라 설계와 코드 작성 시점으로 당겨져야 한다.

### 접근 방식과 아키텍처

Security Agent는 설계검토, 코드리뷰, 침투테스트를 각각 수행하고, 취약점 체인과 권한 상승 가능성까지 검증한다. 단순히 “취약점 있음”을 알려주는 수준을 넘어 수정안과 리포트를 생성하는 것이 개발자 경험 측면에서 중요하다.

### 운영 포인트와 확장 방향

관련 기술 키워드는 AWS Security Agent, secure SDLC, PR review, code remediation, penetration testing, OWASP Top 10, vulnerability chaining이다.

## 정리

이 세션의 핵심은 Agent-Driven 개발 환경, 보안 강화 전략은?를 단순한 기능 소개가 아니라 실제 업무와 운영 환경에 적용하기 위한 조건으로 풀어냈다는 점이다. AI 개발은 취약한 코드가 빠르게 생산·배포될 위험을 키운다.

발표는 AI 활용의 속도를 높이더라도 보안, 접근 제어, 감사, 데이터 보호를 같은 수준으로 설계해야 한다는 메시지로 정리된다.
