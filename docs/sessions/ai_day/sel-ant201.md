## 발표 주제

에이전틱 AI를 도입했지만 "분석할 수 없습니다"만 반복하는 에이전트, 원인은 데이터에 있습니다. AI가 맥락을 이해하고 추론할 수 있도록 데이터를 준비하는 것, 바로 AI-Ready Data입니다. 이 세션에서는 시맨틱 레이어 기반 AI-Ready Data 구축 방법과 라이브 데모를 통해 응답 품질 차이를 확인하고, 구체적인 전환 로드맵을 제공합니다.

에이전틱 AI가 기대만큼 답하지 못하는 원인을 모델이 아니라 데이터 준비 부족에서 찾고, AI-Ready Data와 시맨틱 레이어 구축 방법을 설명했다. 라이브 데모를 통해 데이터 맥락과 의미 계층이 응답 품질을 어떻게 바꾸는지 보여줬다.

## 주요 내용

- 에이전틱 AI는 답변 생성에서 판단과 행동 단계로 넘어가고 있으며, 이때 데이터 맥락이 핵심.
- "분석할 수 없습니다"만 반복하는 에이전트는 모델 문제가 아니라 데이터 의미, 권한, 품질 문제일 가능성이 큼.
- 시맨틱 레이어는 업무 용어, 지표 정의, 관계를 AI가 이해할 수 있는 형태로 제공.
- 프로덕션 전환에는 데이터 품질, 거버넌스, 접근 제어, 평가 기준이 함께 필요.

## 정리

이 세션의 핵심은 AI-Ready Data: 에이전틱 AI 시대, 데이터가 답이다를 단순한 기능 소개가 아니라 실제 업무와 운영 환경에 적용하기 위한 조건으로 풀어냈다는 점이다. 에이전틱 AI는 답변 생성에서 판단과 행동 단계로 넘어가고 있으며, 이때 데이터 맥락이 핵심.
