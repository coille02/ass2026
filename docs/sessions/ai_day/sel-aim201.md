## 발표 주제

엔터프라이즈 AI의 핵심은 기업 고유 요구사항에 맞춘 모델 커스터마이징입니다. 본 세션에서는 Nova Forge로 기업 지식과 워크플로우를 담은 프런티어 모델을 경제적으로 구축하는 방법을 소개하고, Bedrock 강화 미세 조정(RFT)을 통해 방대한 주석 작업 없이 RLVR, RLAIF 등으로 정확도, 안전성, 적응성을 동시에 높이는 기법을 다룹니다.

기업 고유 데이터와 업무 프로세스를 반영한 모델 커스터마이징 방법으로 Nova Forge와 Amazon Bedrock RFT를 소개했다. Nova Forge는 모델 개발 단계별 체크포인트, AWS 큐레이션 데이터, 기업 데이터, 보상 함수를 결합해 기업 맞춤 모델을 만들고, Bedrock RFT는 대규모 라벨 데이터 없이 강화학습 기반으로 정확도와 안전성을 높이는 방법을 제공한다.

## 주요 내용

- 범용 파운데이션 모델은 기업 프로세스와 규제 맥락을 충분히 알지 못하므로 커스텀 모델 수요가 생긴다.
- Nova Forge는 Nova 모델 개발 단계의 체크포인트를 활용해 기업 데이터와 AWS 데이터셋을 블렌딩한다.
- 보상 함수는 “좋은 답변”의 기준을 기업별로 반영하는 장치다.
- Bedrock RFT는 SFT의 데이터 한계를 보완하고, 적은 데이터로도 모델 행동을 강화할 수 있다.

## 세부 내용

### 문제의식과 배경

범용 파운데이션 모델은 기업 프로세스와 규제 맥락을 충분히 알지 못하므로 커스텀 모델 수요가 생긴다. Nova Forge는 Nova 모델 개발 단계의 체크포인트를 활용해 기업 데이터와 AWS 데이터셋을 블렌딩한다.

### 접근 방식과 아키텍처

보상 함수는 “좋은 답변”의 기준을 기업별로 반영하는 장치다. Bedrock RFT는 SFT의 데이터 한계를 보완하고, 적은 데이터로도 모델 행동을 강화할 수 있다.

### 운영 포인트와 확장 방향

관련 기술 키워드는 Amazon Nova Forge, Amazon Bedrock, RFT, RLVR, RLAIF, reward function, S3, custom model, fine-tuning이다.

## 정리

이 세션의 핵심은 Nova Forge와 Bedrock RFT로 모델 성능 극대화를 단순한 기능 소개가 아니라 실제 업무와 운영 환경에 적용하기 위한 조건으로 풀어냈다는 점이다. 범용 파운데이션 모델은 기업 프로세스와 규제 맥락을 충분히 알지 못하므로 커스텀 모델 수요가 생긴다.

발표는 AI 활용이 성과로 이어지려면 모델이나 도구 선택뿐 아니라 데이터, 권한, 운영 절차, 관측 가능성을 함께 설계해야 한다는 메시지로 정리된다.
