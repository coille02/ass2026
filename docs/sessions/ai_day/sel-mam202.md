## 발표 주제

AWS 에이전틱 AI 솔루션을 활용하여 엔터프라이즈 기업의 클라우드 전환을 가속화하는 방법을 소개합니다. 이번 세션에서는 단순한 시스템 마이그레이션과 현대화를 넘어, 레거시 시스템의 심층 분석부터 차세대 시스템 구축까지 End-to-End 자동화를 실현하는 과정을 다룹니다. 먼저 AWS Transform을 통해 레거시 시스템의 현황 분석과 마이그레이션을 자동화하고, 이어서 Kiro를 활용해 최신 코드를 자동으로 생성함으로써 신규 시스템을 신속하게 개발하는 방법을 살펴봅니다. 나아가 Amazon Quick 기반의 데이터 분석까지 기술 스택을 자유롭게 선택하고, 비즈니스 요구에 최적화된 현대화 아키텍처를 설계하는 여정까지 확인할 수 있습니다. 이러한 과정을 통해 기존 레거시 환경의 제약에서 벗어나 수작업을 획기적으로 줄이고, 전환 속도를 크게 단축하며, 기술적 자율성을 확보하는 시나리오를 함께 제시합니다.

레거시 시스템 현대화를 단순 마이그레이션이 아니라 에이전틱 AI 기반 End-to-End 전환으로 보는 세션이다. AWS Transform으로 기존 시스템을 분석하고 마이그레이션 후보를 도출한 뒤, Kiro로 최신 코드와 설계 산출물을 생성하고, Amazon Quick으로 전환 이후 데이터 분석과 업무 활용까지 연결하는 흐름을 제시했다. 요지는 오래된 시스템이 AI 도입의 병목이 되지 않도록 분석, 변환, 개발, 활용 단계를 자동화해야 한다는 것이다.

## 주요 내용

- AI 도입을 이야기하기 전에 기존 IT 시스템이 AI와 연결될 준비가 되었는지 점검해야 한다.
- AWS Transform은 레거시 현황 분석과 전환 작업을 자동화해 수작업 중심 현대화의 속도 문제를 줄인다.
- Kiro는 신규 시스템 개발과 코드 생성 단계에서 프로젝트 맥락을 반영한 자동화 도구로 제시됐다.
- Amazon Quick은 현대화된 데이터와 대시보드를 업무 분석 흐름으로 연결하는 마지막 사용자 경험으로 소개됐다.
