## 발표 주제

우아한형제들은 사내 개발자 누구나 쉽게 LLM을 도입할 수 있도록 "모두를 위한 베드락 LLM Hub"를 구축했습니다. 원클릭 API 키 발급, 투명한 비용 추적, 자바/코틀린 기반 아키텍처로 진입 장벽을 낮추고, Amazon Nova 2 Lite를 활용한 다국어 배달 서비스를 프로덕션에 런칭했습니다. 이 실전 경험을 통해 백엔드 개발자도 LLM 시대의 핵심 인력이 될 수 있음을 확인해 보시기 바랍니다.

우아한형제들이 사내 개발자가 쉽게 LLM을 쓰도록 Bedrock LLM Hub를 만들고, Amazon Nova 2 Lite를 다국어 배달 서비스에 프로덕션 적용한 경험을 공유했다. 세션은 원클릭 API 키 발급, 비용 추적, 자바/코틀린 기반 백엔드 아키텍처로 진입 장벽을 낮춘 점과 실제 번역/다국어 처리 서비스에서 모델 선택보다 시스템 설계가 더 중요했다는 교훈을 강조했다. 마지막에는 LLM 성능을 높이는 적절한 아키텍처가 모델 자체보다 중요할 수 있다는 메시지로 마무리됐다.

## 주요 내용

- "모두를 위한 Bedrock LLM Hub"로 사내 개발자 누구나 LLM API를 쉽게 발급받고 비용을 추적할 수 있게 했다.
- Amazon Nova 2 Lite를 활용해 다국어 배달 서비스 기능을 프로덕션에 적용했다.
- 백엔드 개발자 친화적인 자바/코틀린 아키텍처로 LLM 도입을 특정 AI 팀의 전유물이 아니게 만들었다.
- 모델 선정만큼 요청 라우팅, 필드 단위 번역, 이벤트 흐름, 장애 대응 등 시스템 설계가 중요했다.

## 세부 내용

### 문제의식과 배경

"모두를 위한 Bedrock LLM Hub"로 사내 개발자 누구나 LLM API를 쉽게 발급받고 비용을 추적할 수 있게 했다. Amazon Nova 2 Lite를 활용해 다국어 배달 서비스 기능을 프로덕션에 적용했다.

### 접근 방식과 아키텍처

백엔드 개발자 친화적인 자바/코틀린 아키텍처로 LLM 도입을 특정 AI 팀의 전유물이 아니게 만들었다. 모델 선정만큼 요청 라우팅, 필드 단위 번역, 이벤트 흐름, 장애 대응 등 시스템 설계가 중요했다.

### 운영 포인트와 확장 방향

관련 기술 키워드는 Amazon Bedrock, Amazon Nova 2 Lite, LLM Hub, Java, Kotlin, Multilingual Service, Production LLM이다.

## 정리

이 세션의 핵심은 [우아한형제들] 우아한형제들의 Nova 2 프로덕션 적용 여정를 단순한 기능 소개가 아니라 실제 업무와 운영 환경에 적용하기 위한 조건으로 풀어냈다는 점이다. "모두를 위한 Bedrock LLM Hub"로 사내 개발자 누구나 LLM API를 쉽게 발급받고 비용을 추적할 수 있게 했다.

발표는 AI 활용이 성과로 이어지려면 모델이나 도구 선택뿐 아니라 데이터, 권한, 운영 절차, 관측 가능성을 함께 설계해야 한다는 메시지로 정리된다.
