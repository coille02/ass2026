## 발표 주제

"에이전트가 코드를 수정했는데 동작을 안 합니다." 코딩 에이전트의 흔한 문제는 프로젝트 규칙을 모르고 결과를 검증하지 못하는 것입니다.

이 세션에서는 Kiro의 MCP, Steering, Powers로 프로젝트 지식과 외부 도구를 연결해 Feedback Loop를 구축하는 방법을 다룹니다. 데모를 통해 에이전트의 자율 검증 과정을 확인합니다.

## 주요 내용

- 코딩 에이전트 실패의 흔한 원인은 프로젝트 규칙과 검증 방법을 모르는 상태에서 코드를 수정하는 것이다.
- Steering은 팀의 개발 규칙, 아키텍처 원칙, 코딩 컨벤션을 에이전트에 지속적으로 주입하는 장치로 소개됐다.
- MCP와 Powers를 통해 이슈, 문서, 테스트, 외부 API를 연결하면 에이전트가 수정 후 검증까지 수행할 수 있다.
- 개발 효율은 코드 생성 속도보다 피드백 루프의 짧아짐에서 나온다.
- 주요 기술과 키워드는 Kiro, MCP, Steering, Powers, Developer Tools, Feedback Loop, AI Coding Agent 중심으로 정리됐다.
