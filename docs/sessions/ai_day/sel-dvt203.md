## 발표 주제

AI-DLC는 AI와 사람의 협업 모델을 기반으로 소프트웨어 개발 방식을 근본적으로 혁신하는 AI 네이티브 개발 방법론입니다. 본 세션에서는 AI-DLC 워크플로우를 소개하고, 이러한 패러다임 전환이 개발자와 조직, 비즈니스에 가져다줄 변화와 이점을 다룹니다. 특히 큰 규모의 코드베이스 환경에서 AI-DLC를 도입한 LG전자의 사례와 그 과정에서 얻은 교훈을 공유합니다.

단순 코드 생성 도구 도입만으로는 SDLC 전체 생산성이 크게 오르지 않는다는 문제의식에서, 요구사항 정의부터 UX/UI 설계, 기술 의사결정, 코드 생성, 테스트, 배포까지 AI와 사람이 협업하는 AI-DLC 방법론을 소개했다. LG전자는 대규모 코드베이스와 기존 SRS/HLD/LLD 산출물 체계를 반영해 조직 맞춤형 워크플로우를 설계했고, 산출물 간 컨텍스트 단절을 줄이는 데 초점을 뒀다.

## 주요 내용

- AI-DLC는 Inception, Construction, Operation 단계로 요구사항, 설계, 구현, 테스트, 배포를 연결한다.
- AI가 모든 결정을 대신하는 방식보다, 사람의 의도와 의사결정을 문서화하고 다음 단계 컨텍스트로 넘기는 방식이 중요하다.
- 대규모 레거시 현대화에서는 기존 의사결정, API 경계, 테스트 케이스, 외부 컨텍스트를 명시적으로 수집해야 한다.
- LG전자 사례에서는 문서 생성 속도보다 사람이 읽고 판단하는 속도가 병목이 될 수 있어, 리뷰 가능한 산출물 크기와 단계 분리가 중요했다.
