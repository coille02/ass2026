## 발표 주제

여러분의 핵심 데이터로 엔드투엔드 에이전틱 AI 애플리케이션 구축 실전 노하우를 공유합니다. MCP와 RAG 기반 데이터 관리, Aurora, OpenSearch 베스트 프랙티스 아키텍처, SageMaker Unified Studio 분석 기능, 데이터 레이크, 거버넌스, 품질 관리와 Bedrock AgentCore 통합 방법을 알아봅니다.

챗봇, RAG, MCP, 자율 에이전트로 이어지는 변화 속에서 에이전트가 실제 업무를 수행하려면 데이터 접근, 맥락, 권한, 거버넌스가 함께 설계되어야 한다는 실무 가이드. 보험사 예시를 통해 에이전틱 애플리케이션을 데이터 기반으로 구성하는 흐름을 설명했다.

## 주요 내용

- 2023년 챗봇/벡터 중심에서 RAG, MCP, 자율 에이전트로 빠르게 이동 중.
- 에이전트는 도구 호출과 데이터 접근을 하기 때문에 단순 검색 품질보다 권한, 출처, 품질 관리가 중요.
- Aurora, OpenSearch, 데이터 레이크, SageMaker Unified Studio 등을 조합해 분석과 검색 기반을 구성.
- Bedrock AgentCore 통합 시 데이터 거버넌스와 도구 호출 정책을 함께 설계해야 함.

## 세부 내용

### 문제의식과 배경

2023년 챗봇/벡터 중심에서 RAG, MCP, 자율 에이전트로 빠르게 이동 중. 에이전트는 도구 호출과 데이터 접근을 하기 때문에 단순 검색 품질보다 권한, 출처, 품질 관리가 중요.

### 접근 방식과 아키텍처

Aurora, OpenSearch, 데이터 레이크, SageMaker Unified Studio 등을 조합해 분석과 검색 기반을 구성. Bedrock AgentCore 통합 시 데이터 거버넌스와 도구 호출 정책을 함께 설계해야 함.

### 운영 포인트와 확장 방향

관련 기술 키워드는 MCP, RAG, Aurora, Amazon OpenSearch Service, SageMaker Unified Studio, Data Lake, Bedrock AgentCore, 데이터 거버넌스이다.

## 정리

이 세션의 핵심은 에이전틱 AI를 위한 데이터 실무 가이드를 단순한 기능 소개가 아니라 실제 업무와 운영 환경에 적용하기 위한 조건으로 풀어냈다는 점이다. 2023년 챗봇/벡터 중심에서 RAG, MCP, 자율 에이전트로 빠르게 이동 중.

발표는 AI 품질을 높이기 위해 데이터의 의미, 출처, 품질, 접근 권한을 함께 관리해야 한다는 메시지로 정리된다.
