## 발표 주제

속도 경쟁은 결코 피할 수 없는 과제가 되었습니다. 보안 프로세스보다 더 빠르게 코드를 짜고 배포하는 AI 에이전트들 사이에서, 인프라 걱정없이 안전하게 배포하는 플랫폼이 필요합니다. 본 세션은 Cloudflare를 통해 거버넌스와 격리 환경을 구축하고, 신뢰할 수 없는 코드도 안심하고 배포하며 AI 에이전트 개발 속도를 극대화하는 방법을 소개합니다.

AI 에이전트가 코드를 작성하고 실행하며 DB 조회와 API 호출까지 수행하는 시대에는 “빠른 배포”와 “권한·감사·격리”가 함께 필요하다고 설명했다. Cloudflare AI Gateway, MCP 서버 포털, 샌드박스 실행 환경을 통해 에이전트의 LLM 호출, 도구 접근, 데이터 유출, 무한 루프, 권한 남용을 통제하는 접근을 제시했다.

## 주요 내용

- 2023년의 AI가 텍스트 생성 도구였다면 2026년의 AI 에이전트는 실행 주체에 가깝다.
- 에이전트에는 직원처럼 신원, 최소 권한, 정책, 감사 로그, 격리된 실행 환경이 필요하다.
- MCP 서버 포털은 승인된 도구만 사용하게 하는 관문 역할을 한다.
- AI Gateway는 LLM 트래픽의 제어 지점으로 DLP, 사용량 제한, 루프 탐지, 소스코드/PII 유출 방지에 활용된다.

## 세부 내용

### 문제의식과 배경

2023년의 AI가 텍스트 생성 도구였다면 2026년의 AI 에이전트는 실행 주체에 가깝다. 에이전트에는 직원처럼 신원, 최소 권한, 정책, 감사 로그, 격리된 실행 환경이 필요하다.

### 접근 방식과 아키텍처

MCP 서버 포털은 승인된 도구만 사용하게 하는 관문 역할을 한다. AI Gateway는 LLM 트래픽의 제어 지점으로 DLP, 사용량 제한, 루프 탐지, 소스코드/PII 유출 방지에 활용된다.

### 운영 포인트와 확장 방향

관련 기술 키워드는 Cloudflare AI Gateway, MCP server portal, AI agent sandbox, DLP, policy control, audit log, least privilege이다.
