- 요약 근거: VOD 음성 전사 기반

**핵심 요약**

GS SHOP은 홈쇼핑과 숏폼 영상 속 장면, 분위기, 사용 맥락을 AI로 이해하고 이를 추천 신호로 바꿔 기존 상품 중심 추천을 확장했다. 발표의 핵심은 영상을 단순한 콘텐츠나 상품 메타데이터가 아니라, 고객이 어떤 메시지에 반응했는지를 보여주는 취향 신호로 재해석했다는 점이다. TwelveLabs의 영상 이해 모델과 Amazon Bedrock 기반 모델들을 활용해 영상에서 `소구 포인트`를 추출하고, 이를 기존 추천 엔진에 결합하는 하이브리드 추천 구조를 만들었다. 약 2주간의 A/B 테스트에서 클릭, 주문, 전환율 모두 유의미하게 개선됐다고 발표했다.

**주요 포인트**

- AWS는 영상 AI 접근법을 `분할`, `보강`, `이해`의 3단계로 설명했다. 긴 영상을 맥락 전환 기준으로 나누고, 상품/브랜드/카탈로그 데이터를 연결한 뒤, VLM과 임베딩 모델로 의미를 벡터화하는 흐름이다.
- GS SHOP은 방송 종료 후 숏폼 등 2차 콘텐츠를 만들 때 라이브 전용 멘트, 변경된 혜택, 상품 구성 변경 등을 사람이 직접 찾아 제거해야 했다. 1시간 영상 편집에 1-2시간이 걸리는 문제에서 “영상도 텍스트처럼 검색할 수 있지 않을까?”라는 출발점이 생겼다.
- TwelveLabs의 `Marengo` 모델은 자연어 질의로 긴 홈쇼핑 영상 속 특정 장면을 찾는 데 활용됐다. 예컨대 쇼핑호스트의 시식 장면처럼 객체, 행동, 장면의 연속성이 함께 필요한 검색도 가능하다고 설명했다.
- GS SHOP은 검색을 넘어 추천으로 확장하기 위해 `Pegasus`를 활용했다. 단, 영상 전체 설명을 그대로 임베딩하면 상품명, 브랜드, 스펙 중심으로 치우쳐 추천 결과가 좁아지는 한계가 있었다.
- 이를 해결하기 위해 추천에 필요한 맥락만 남기는 `소구 포인트`를 정의했다. 예시는 통기성, 착화감, 편안한 활동성, 일상 활용성, 스타일, 사용 상황 같은 고객 반응 유발 메시지다.
- 구조는 영상 이해, 소구 포인트 추출, 임베딩, 유사도 계산으로 이어진다. Pegasus가 영상을 이해하고, Claude Sonnet 계열 모델이 맥락을 구조화하며, Cohere Embed 계열 임베딩으로 벡터화해 유사한 영상을 찾는 흐름이다.
- 추천 시스템은 기존 상품 중심 추천을 대체하지 않고 확장했다. 기존의 상품/카테고리 점수에 쇼폼 맥락 점수를 더하고, 다양성 후처리를 거쳐 최종 추천 리스트를 만든다.
- 고객 행동도 단순 클릭이 아니라 의도로 분류했다. 상품 상세 진입은 구매 의도, 영상 재생/썸네일 클릭은 탐색 의도, 단순 노출이나 중단 행동은 제외하는 방식으로 선호 벡터를 구성했다.
- 약 2주간 A/B 테스트에서 일부 추천 영역 기준 클릭 약 21.7%, 주문 약 57.5%, 전환율 약 29.4% 증가가 발표됐다.
- 향후 방향은 추천에서 검증한 소구 포인트를 다시 콘텐츠 제작에 활용하고, Bedrock의 영상 생성 모델까지 연결해 콘텐츠 제작과 추천이 서로 학습하는 선순환을 만드는 것이다.
