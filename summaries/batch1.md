# AWS Summit Seoul 2026 Industry Day - Batch 1 Summaries

## sel-key001

- 제목: 기조연설 - Industry Day
- 시간: 2026-05-20 09:30-10:40 KST
- 트랙: AWS Summit Seoul - Keynote
- 발표자: 함기호 (대표이사, AWS Korea), Jason Bennett (Vice President, Worldwide Startups and VC, AWS), 김성훈 (대표, Upstage), 김 환 (CTO, CJ OliveYoung)
- 근거: VOD 전사 시도 결과 음성 구간 없이 10분 길이 헤더만 생성되어 메타데이터 기반으로 정리

### 핵심 요약
Industry Day 기조연설은 아이디어를 실제 비즈니스 성과로 바꾸기 위해 AWS가 제공하는 AI, 클라우드 현대화, 보안 역량을 큰 흐름으로 소개하는 세션이다. AWS 글로벌 스타트업 총괄 Jason Bennett이 최신 AI 전략과 개발자 생산성, 에이전틱 시스템 활용 방향을 제시하고, Upstage와 CJ OliveYoung 사례를 통해 한국 기업의 AI 적용 성과를 보여주는 구성으로 안내되어 있다. 세션의 핵심 메시지는 생성형 AI를 단일 기능이 아니라 개발, 워크로드 현대화, 보안, 산업별 혁신을 묶는 실행 플랫폼으로 봐야 한다는 점이다.

### 주요 포인트
- AWS의 최신 AI 전략을 Industry Day 전체 맥락의 출발점으로 제시
- 에이전틱 시스템을 통한 개발자 역량 강화와 업무 자동화 방향 소개
- Upstage와 CJ OliveYoung 사례를 통해 국내 기업의 AI 적용 성과 강조
- 워크로드 현대화와 전 세계 기업 보안 강화에서 AWS 클라우드의 역할 설명
- 후속 산업별 세션으로 이어지는 공통 주제인 AI 실행력과 비즈니스 전환을 개괄

### AWS/기술 키워드
- 생성형 AI, 에이전틱 AI, 워크로드 현대화, 보안, 스타트업, 개발자 생산성, Industry Day keynote

### 현장 메모로 남길 점
- 전사 결과가 실세션 음성이 아닌 프리쇼/슬레이트 수준으로 보이며, 세부 발언 요약은 공식 메타데이터 기반으로만 작성했다.

### 블로그용 한줄
> AWS Summit Seoul 2026 Industry Day의 기조연설은 AI를 아이디어에서 운영 가능한 혁신으로 옮기는 AWS의 큰 전략 지도를 제시했다.

## sel-ind226

- 제목: Amazon's AI Strategy
- 시간: 2026-05-20 11:10-11:50 KST
- 트랙: AWS Summit Seoul - Track 1
- 발표자: 김기완 (AWS 코리아 테크리더, AWS), 이현석 (GTM리더, AWS)

### 핵심 요약
이 세션은 Amazon이 AI를 고객 경험, 셀러 지원, 공급망과 물류 운영 전반에 적용해 온 방식을 통해 AWS의 AI 전략을 설명했다. 발표자는 AI가 빠르게 채택되는 기술이며, Amazon은 내부에서 축적한 경험과 기술을 AWS 서비스와 솔루션으로 고객에게 전달한다는 전략을 강조했다. 예시로 Rufus 쇼핑 어시스턴트, 셀러 상품 등록 자동화, Help Me Decide 같은 에이전틱 서비스, Chronos 기반 수요 예측, 로봇과 디지털 트윈 기반 물류 혁신이 언급됐다. 후반부는 Bedrock의 모델 선택권, Anthropic Claude와의 통합, 폐쇄망/보안 요구를 고려한 AWS 기반 AI 운영 방향으로 이어졌다.

### 주요 포인트
- Amazon의 AI 전략은 고객 경험 혁신을 위해 전 가치사슬에 AI를 내재화하고 이를 AWS 서비스로 확장하는 구조
- 쇼핑 영역에서는 Rufus와 에이전틱 AI 서비스가 고객 의사결정과 구매 경험을 지원
- 셀러 영역에서는 사진과 간단한 설명을 바탕으로 상품 콘텐츠 생성을 자동화해 등록 부담을 줄임
- 공급망 영역에서는 Chronos 기반 시계열 예측, 로봇 운영, NVIDIA Isaac 기반 디지털 트윈과 강화학습으로 예측과 자동화를 고도화
- AWS 관점에서는 Bedrock, Claude 통합, 네트워크 격리와 거버넌스를 통해 기업형 AI 운영 선택지를 제공

### AWS/기술 키워드
- Amazon Bedrock, Amazon Nova, Anthropic Claude, Rufus, Chronos, Agentic AI, 디지털 트윈, NVIDIA Isaac, 로봇 자동화, 개인화

### 현장 메모로 남길 점
- "고객은 낮은 가격, 많은 선택지, 좋은 경험을 원한다"는 Amazon식 원칙을 AI 전략의 판단 기준으로 반복해 설명한 점이 인상적이다.

### 블로그용 한줄
> Amazon의 AI 전략은 거대한 AI 비전을 말하기보다 쇼핑, 셀러, 물류 현장의 반복 문제를 AI 서비스로 제품화한 실행 사례에 가까웠다.

## sel-ind234

- 제목: [GS리테일] 숏폼 시대, GS SHOP의 영상기반 AI 상품 추천플랫폼 구축기
- 시간: 2026-05-20 11:10-11:50 KST
- 트랙: AWS Summit Seoul - Track 2
- 발표자: 임해인 (솔루션즈 아키텍트, AWS), 조민규 (매니저, GS 리테일), 이세윤 (매니저, GS 리테일)

### 핵심 요약
GS SHOP은 텍스트와 메타데이터 중심 추천만으로는 숏폼, 라이브커머스, 리뷰 영상 속 고객 맥락을 충분히 반영하기 어렵다고 보고 영상 기반 추천 플랫폼을 구축했다. 세션은 비디오 분석 파이프라인과 임베딩 기반 의미 검색의 개념을 설명한 뒤, GS리테일이 상품 정보, 방송 영상, 고객 행동 로그를 연결해 추천 신호를 재정의한 과정을 다뤘다. 핵심은 카테고리나 브랜드처럼 이미 구조화된 신호를 반복하지 않고, 영상만이 보여줄 수 있는 기능성, 스타일과 감성, 사용 상황, 장면의 메시지를 추출하는 것이다. 이를 통해 영상의 장면과 분위기를 이해해 고객이 실제로 반응할 만한 상품 추천으로 확장했다.

### 주요 포인트
- 영상 생산과 소비가 폭발적으로 증가하면서 커머스 추천에서도 영상 이해가 중요한 입력값이 됨
- 비디오 분석은 콘텐츠 이해, 임베딩/인덱싱, 검색과 추천으로 이어지는 공통 파이프라인으로 발전
- 영상 임베딩은 "비슷한 장면"이나 "특정 분위기" 같은 자연어 기반 의미 검색과 개인화 추천을 가능하게 함
- GS SHOP은 기존 상품 메타데이터와 중복되는 카테고리/브랜드보다 영상 속 메시지와 사용 맥락을 별도 신호로 추출
- 영상 전체를 길게 설명하기보다 고객 반응과 연결되는 핵심 메시지를 구조화해 추천 품질을 높이는 접근을 선택

### AWS/기술 키워드
- Amazon Bedrock, TwelveLabs, 비디오 이해 모델, 임베딩, 벡터 검색, 개인화 추천, 라이브커머스, 영상 분석 파이프라인

### 현장 메모로 남길 점
- 영상 추천의 차별점은 "영상도 데이터로 쓴다"가 아니라 기존 메타데이터가 설명하지 못하는 감성, 상황, 스타일 신호를 분리해 쓰는 데 있었다.

### 블로그용 한줄
> GS SHOP은 상품 영상을 단순 콘텐츠가 아니라 고객 취향을 읽는 추천 신호로 바꾸며 숏폼 시대의 커머스 AI 방향을 보여줬다.

## sel-ind208

- 제목: [KB국민은행] KBaaS, 금융이 플랫폼 속으로 : KB국민은행의 임베디드 금융 전략과 API 인프라 현대화
- 시간: 2026-05-20 11:10-11:50 KST
- 트랙: AWS Summit Seoul - Track 3
- 발표자: 이미리내 (테크니컬 어카운트 매니저, AWS), 김우진 (매니저, KB국민은행)

### 핵심 요약
KB국민은행은 금융 기능이 비금융 플랫폼 안에서 API 형태로 호출되는 임베디드 금융 시대에 맞춰 KBaaS와 API 인프라를 현대화했다. 발표는 슈퍼앱과 AI 기반 금융 호출이 확산되면서 안정적이고 확장 가능한 고성능 API 인프라가 금융사의 핵심 경쟁력이 됐다고 설명했다. KB국민은행은 외부 솔루션과 온프레미스 중심 구조에서 자체 구축 게이트웨이와 클라우드 네이티브 구조로 전환했고, EKS 기반으로 서비스 유형별 노드 그룹과 스케일아웃 구조를 설계했다. Aurora DB와 캐시 조합을 성능과 비용 관점에서 검증해 과도한 분산 캐시 의존을 줄이고 운영 유연성을 확보한 점도 주요 내용이었다.

### 주요 포인트
- 결제, 예금, 인증 같은 금융 기능이 외부 플랫폼에서 API로 호출되는 구조가 확대됨
- KB국민은행은 1,800여 개 API와 일 2억 건 규모 호출을 처리하는 KBaaS 인프라를 고도화
- 외부 API 게이트웨이 솔루션은 운영 부담을 낮추지만 비용, 신규 요구 대응, 보안 취약점 조치 측면의 제약이 있어 자체 구축을 선택
- EKS 기반 구조에서 ALB가 경로별로 적절한 노드 그룹에 트래픽을 전달하고 사용량에 따라 스케일아웃하도록 설계
- Aurora DB, 내부 캐시, 분산 캐시 조합을 비교해 성능과 비용의 균형점을 찾음

### AWS/기술 키워드
- Amazon EKS, Amazon Aurora, ALB, Kubernetes, API Gateway, KBaaS, 임베디드 금융, 클라우드 네이티브, 캐시 전략

### 현장 메모로 남길 점
- 자체 구축은 단순히 비용 절감 목적이 아니라 금융 API의 변경 속도, 보안 대응, 제휴 확장성을 통제하기 위한 전략적 선택으로 설명됐다.

### 블로그용 한줄
> KB국민은행의 KBaaS 사례는 금융사가 API 인프라를 제품처럼 운영해야 하는 시대가 왔음을 보여줬다.

## sel-ind213

- 제목: [웅진씽크빅] 웅진씽크빅의 AI-DLC를 활용한 교육자용 AI 에이전트 구축기
- 시간: 2026-05-20 11:10-11:50 KST
- 트랙: AWS Summit Seoul - Track 4
- 발표자: 이다은 (솔루션즈 아키텍트, AWS), 곽태호 (기술총괄부문장, 웅진씽크빅)

### 핵심 요약
웅진씽크빅은 AI 코딩 도구가 빠르게 확산되고 있지만 결과물이 완벽하지 않다는 현실을 전제로, AI-DLC와 Kiro를 활용해 개발 과정을 구조화했다. 세션은 단순히 코드를 빠르게 작성하는 것을 넘어 요구 정의, 개발, 테스트, 배포, 운영까지 AI를 개발 생애주기 안에 배치하는 접근을 설명했다. 웅진씽크빅은 학습 컨설턴트와 현장 조직의 업무를 개선하는 과제를 발굴하고, AI 에이전트를 통해 생산성과 고객 경험을 높이는 방향으로 AX를 추진했다. 사람은 검토와 승인, 결함 관리처럼 판단이 필요한 단계에 남기고 반복 작업은 에이전트화하는 구성이 핵심이었다.

### 주요 포인트
- AI 코딩 도구의 생산성 효과를 실제 서비스 품질과 운영 안정성으로 연결하려면 생애주기 관점의 방법론이 필요
- AI-DLC는 아이디어, 개발, 테스트, IaC 배포, 운영 관리까지 단계별로 AI 활용 방식을 정리
- 웅진씽크빅은 만 명 규모의 현장 인력 업무가 10-20%만 개선돼도 큰 비즈니스 효과가 난다고 보고 현장 과제부터 발굴
- 교육자와 학습 컨설턴트를 위한 AI 에이전트 구축 과정에서 사람의 검토, 확인, 승인 단계를 유지
- 도입 후 개발 방식과 현장 업무 방식이 함께 바뀌며 서비스와 업무 프로세스 개선 속도가 빨라졌다고 공유

### AWS/기술 키워드
- Kiro, AI-DLC, AI Agent, AX, IaC, Human-in-the-loop, 교육 AI, 개발 생애주기

### 현장 메모로 남길 점
- 발표의 초점은 특정 모델보다 "AI로 개발하는 절차"를 조직 운영 방식에 맞게 정착시키는 데 있었다.

### 블로그용 한줄
> 웅진씽크빅은 Kiro와 AI-DLC를 활용해 교육 현장의 반복 업무를 AI 에이전트와 사람의 검토 체계가 함께 처리하는 방식으로 바꿨다.

## sel-ind216

- 제목: [현대자동차] 현대자동차의 AI 기반 마켓인텔리전스 혁신 (AI for MI)
- 시간: 2026-05-20 11:10-11:50 KST
- 트랙: AWS Summit Seoul - Track 5
- 발표자: 선우경희 (센터장, 현대자동차), 김수빈 (책임매니저, 현대자동차)

### 핵심 요약
현대자동차 MI센터는 자동차 산업의 변화 속에서 시장 예측을 단순 수치 도출이 아니라 고객, 기술, 경쟁, 모빌리티 수요의 변동 요인을 읽는 업무로 정의했다. 이를 위해 정형 데이터와 뉴스, 이벤트, 소셜미디어, 리포트, 인터뷰 같은 비정형 데이터를 중앙 데이터 레이크로 모으고 AI 기반 분석 체계를 구축했다.
